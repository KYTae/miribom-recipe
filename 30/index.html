No.30따라하기릴스 #30

클로드 클레이 장인, 스킬로 풀렸다 — 점토 애니 스킬 설치부터 내 캐릭터 영상까지 (Claude Code + Blender)

28편에서 Claude가 Blender로 점토 애니를 빚는 걸 봤죠. 이번엔 그 기술이 누구나 쓰는 "스킬"로 풀렸어요. Miguel(@angrypenguinPNG)이 오픈소스로 공개한 blender-claymation 스킬을 Claude Code에 넣고 "이글루에 사는 펭귄 클레이 애니 만들어줘" 한 줄을 넣었더니, 눈 내리는 밤 털모자 펭귄이 뒤뚱뒤뚱 나와 눈송이에 재채기하는 20초 1080p 영상이 나왔어요. 처음부터 끝까지 약 1시간. 3D를 몰라도 따라 할 수 있게 설치 명령어, 내 캐릭터 프롬프트, 고퀄로 만드는 요령까지 정리했어요.

스킬이 뭘 해줘요?

how it works

한 줄 아이디어만 주면, 작은 애니 스튜디오처럼 순서대로 일해요

이렇게 작동해요

  1. 1한 줄 아이디어"이글루에 사는 펭귄"
  2. 2비트 시트240프레임(20초)을 장면별로 나눔
  3. 3세트·인형 제작Blender Python으로 점토 재질·조명·카메라
  4. 4테스트 → 렌더스틸 확인 → Cycles 렌더 → mp4

스킬은 Claude에게 주는 "작업 설명서 + 도구 상자"예요. 이 스킬에는 점토 재질을 만드는 코드(claylib.py), Blender를 화면 없이 돌리는 스크립트, 프레임을 mp4로 합치는 스크립트, 그리고 펭귄·클레이 공 예제 2편이 들어 있어요. Claude는 설명서대로 이야기를 프레임 단위로 짜고, 책상 위 미니어처와 점토 인형을 코드로 만들고, 1초에 12번만 움직이는 스톱모션 방식으로 애니메이션한 뒤, 테스트 장면을 직접 보고 고친 다음 전체를 렌더해요.

준비물

  • Claude Code내 컴퓨터에서 돌아가는 Claude. Pro 이상 요금제가 필요하고, 원본은 Opus 5.5로 만들었어요.
  • Blender 4.2 이상무료 3D 프로그램 (5.2에서 테스트). 아래 명령어 한 줄로 설치돼요.
  • ffmpeg · git프레임을 영상으로 합치는 무료 도구와, 스킬을 내려받는 도구.
  • 그래픽카드(있으면 좋아요)렌더 속도가 크게 달라요. M4 Pro 맥에서 20초(1600x900) 렌더가 약 25~30분. GPU가 없으면 해상도·샘플을 절반으로.
  • 음악 (선택)원본 펭귄 영상의 음악은 ElevenLabs Music으로 따로 만들었어요. 스킬 자체는 무음 영상을 만들어요.

method
01STEP 1원본

원본 · 펭귄 한 줄로 20초 클레이 단편

  • Miguel은 “Opus 5.5는 프롬프트 하나로 Blender에서 클레이메이션을 만든다, 스킬을 오픈소스로 풀었으니 직접 만들어 보라”며 영상을 올렸어요(Alex Albert의 클레이 영상을 보고 만든 스킬). 영상 속 Claude는 펭귄 단편
    를 완성하고 이렇게 설명해요. 해 질 녘 눈 내리는 이글루, 털모자와 줄무늬 목도리를 한 펭귄이 뒤뚱뒤뚱 나와 두리번거리다, 부리에 눈송이가 앉자 사팔눈이 되고
    1. 1아래 설치를 마친 뒤 Claude Code 실행
    2. 2원본 프롬프트(영어)나 한국어 번역을 그대로 붙여넣기
    3. 3Claude가 비트 시트 → 테스트 스틸 → 전체 렌더 순서로 진행 상황을 알려줘요
    4. 4완성된 mp4와 콘택트 시트(장면 모음 이미지) 확인
  • 원본 프롬프트 (스킬 README 예시, 영어)
    can you make a stop motion claymation video (~20 seconds) of a little penguin who lives in an igloo?
  • 같은 내용 한국어
    이글루에 사는 아기 펭귄이 나오는 20초 정도의 스톱모션 클레이 애니메이션 영상을 만들어줄 수 있어?
  • 영상 속 Claude가 꼽은 "스튜디오처럼 보이는 이유"
    • 카메라 3대(와이드·클로즈업·미디엄)를 컷마다 고정 — 진짜 스톱모션 세트처럼
    • 1초에 12번만 움직이고, 멈춘 자세에서도 살짝 흔들림 + 점프할 때 찌그러졌다 늘어남
    • 털모자 니트 무늬, 방울과 목도리 끝이 몸을 따라 흔들림, 눈 위 발자국, 얕은 심도
    • 마지막에 조명 글로우·색 보정·비네팅·필름 그레인
  • TIP원본 음악은 ElevenLabs Music으로 4곡을 뽑아 "펭귄이 손 흔드는 순간 마지막 화음이 떨어지는" 곡을 골랐대요. 음악은 따로 붙이거나 CapCut에서 넣어도 돼요.
02STEP 2설치

설치 · 명령어 복사해서 붙여넣기

  • 터미널(맥) 또는 PowerShell(윈도우)을 열고 아래 명령어를 한 줄씩 붙여넣으면 돼요. 마지막 줄이 스킬을 Claude Code의 스킬 폴더(~/.claude/skills)에 넣는 명령이에요. 넣고 나면 Claude Code가 "클레이메이션·스톱모션·점토 애니" 요청을 받을 때 알아서 이 스킬을 꺼내 써요.
  • 맥 — 터미널에 한 줄씩
    brew install --cask blender
brew install ffmpeg
curl -fsSL https://claude.ai/install.sh | bash
git clone https://github.com/angrypenguinpng/blender-claymation-skill ~/.claude/skills/blender-claymation
  • 윈도우 — PowerShell에 한 줄씩
    winget install BlenderFoundation.Blender
winget install Gyan.FFmpeg
winget install Git.Git
irm https://claude.ai/install.ps1 | iex
git clone https://github.com/angrypenguinpng/blender-claymation-skill "$HOME\.claude\skills\blender-claymation"
    1. 1명령어를 다 넣었으면 터미널을 껐다 켜기 (새로 깐 프로그램을 인식하게)
    2. 2아무 폴더나 만들고 그 안에서 claude 입력 → 로그인
    3. 3"blender-claymation 스킬 보여?"라고 물어서 스킬이 잡혔는지 확인
    4. 4Blender를 못 찾는다고 하면 "Blender 설치 경로 찾아서 써줘"라고 말하기
  • 주의스킬은 Claude가 Blender에서 Python 코드를 실행하게 해요. 중요한 파일이 있는 폴더 말고 새 작업 폴더에서 시작하세요. 윈도우에서 Blender 경로를 못 찾으면 C:\Program Files\Blender Foundation 아래를 알려주면 돼요.
03STEP 3첫 영상

첫 영상 · 테스트 스틸 → 전체 렌더

  • 스킬의 설명서(SKILL.md)는 바로 전체 렌더하지 말고 "싼 스틸로 먼저 보라"고 해요. 장면마다 960x540 한 장씩, 샘플 32로 뽑으면 몇 초~몇 분이면 끝나요. 여기서 마음에 들 때만 1600x900·샘플 80으로 240프레임을 렌더하세요. 렌더가 끝나면 Claude가 프레임을 mp4로 합치고(그레인·비네팅 포함), 장면 20개를 한 장에 모은 콘택트 시트로 튀거나 떠 있는 곳이 없는지 확인해요.
  • 첫 요청 (한국어 한 줄)
    20초짜리 스톱모션 클레이 애니메이션 만들어줘. 주인공은 (주황색 아기 고양이)이고, (아침 햇살 드는 책상 위 머그컵 안에서 깨어나 기지개를 켜고 책 위로 폴짝 뛰어오르는) 이야기야.
  • 렌더 전에 미리보기만
    전체 렌더 전에, 이야기의 핵심 장면 5개만 960x540·샘플 32로 한 장씩 렌더해서 한 장에 모아 보여줘. 내가 확인하면 그때 전체를 렌더해줘.
  • 테스트 스틸에서 볼 5가지 (스킬 설명서 기준)
    • 노출: 점토가 파스텔처럼 허옇게 뜨면 너무 밝아요 → "노출 낮춰줘"
    • 닿음: 발·팔이 바닥에 붙어 있는지, 떠 있거나 파묻히지 않았는지
    • 눈: 작은 썸네일에서도 눈이 보이는지
    • 구도: 수평선 위치, 캐릭터가 보는 쪽에 여유 공간
    • 보케: 뒤쪽 작은 조명이 동그랗게 흐려 보이는지
  • TIP고칠 곳이 생기면 전체를 다시 렌더하지 말고 "120~150프레임만 다시 렌더해줘"처럼 구간만 말하세요. 스킬에 --range 옵션이 있어서 그 부분만 다시 뽑아요.
04STEP 4응용

응용 · 내 캐릭터로 바꾸기

  • 괄호 안만 바꾸면 내 캐릭터 영상이 돼요. 주인공은 "누구 + 소품 하나"(털모자 펭귄, 우산 든 달팽이), 무대는 "언제 + 어디"(비 오는 오후 창틀), 이야기는 화살표로 4~5단계면 20초에 딱 맞아요. 마지막은 카메라를 보고 끝내야 귀엽게 마무리돼요.
  • 미리봄 내 캐릭터 프롬프트 (한국어)
    blender-claymation 스킬로 20초짜리 스톱모션 클레이 애니메이션을 만들어줘.

[주인공] (빨간 털모자를 쓴 아기 펭귄) — 키 6~8cm 점토 인형, 눈은 반짝이는 검은 구슬
[무대] (눈 내리는 저녁, 불 켜진 이글루 앞) — 책상 위 미니어처 세트, 뒤쪽에 흐린 보케 조명
[이야기] (이글루에서 빼꼼 → 뒤뚱뒤뚱 걸어 나옴 → 눈송이가 부리에 앉음 → 에취! → 깡충 뛰고 손 흔들기)
[마무리] 카메라를 보고 웃으며 끝

진행 방식:
1) 먼저 프레임 번호로 비트 시트를 보여줘 (20초 = 12fps 240프레임).
2) 장면마다 960x540 테스트 프레임을 뽑아서 노출·발 닿음·눈·구도를 직접 확인하고 고쳐.
3) 괜찮으면 1600x900으로 전체 렌더 → mp4로 합쳐서 줘. 콘택트 시트도 같이.
  • 같은 내용 영어
    Use the blender-claymation skill to make a ~20 second stop-motion claymation film.

Hero: (a baby penguin in a red knitted hat), a 6-8 cm clay puppet with glossy black bead eyes.
Set: (a snowy evening outside a glowing igloo), a tabletop miniature with soft bokeh lights behind.
Story: (peeks out of the igloo → waddles out → a snowflake lands on its beak → sneezes → hops and waves).
Ending: faces the camera and smiles.

Process: 1) show me a beat sheet in frame numbers first (20 s = 240 frames at 12 fps). 2) render a 960x540 test still for each beat and check exposure, contact, eyes and composition yourself. 3) then render the full film at 1600x900, encode an mp4 and give me a contact sheet too.
  • 이런 주인공이 잘 나와요
    • 동물 + 소품: 목도리 두른 아기 여우, 헬멧 쓴 거북이
    • 음식 캐릭터: 김이 나는 만두, 졸린 식빵, 수박 조각
    • 사물 캐릭터: 탁상시계, 머그컵, 작은 화분
    • 우리 반려동물: "갈색 곱슬머리 토이푸들" 처럼 색·털·크기를 적기
  • 이건 피하세요
    • 등장인물 3명 이상 — 20초에 다 못 보여줘요
    • 실존 인물·유명 캐릭터 — 공개·상업 이용 시 문제가 될 수 있어요
    • 물·불·연기가 주인공 — 점토 느낌이 잘 안 나요
05STEP 5고퀄

고퀄 · 진짜 점토처럼 보이게 하는 숫자

  • 스킬에 들어 있는
    는 예제 영상에서 뽑은 숫자 모음이에요. 결과가 CG처럼 매끈해 보이면 이 숫자를 그대로 말해 주면 돼요. 가장 큰 차이는 움직임이에요. 부드럽게 이어지는 움직임이
  • 움직임
    • 12fps "on twos" — 매 프레임 키를 찍고 보간 없이 뚝뚝
    • 꿈틀거림: 인형마다 약 0.2mm·0.2° 랜덤 흔들림, 세트는 고정
    • 걷기는 3프레임마다 자세 바꾸기
    • 점프: 뛰기 전 12~18% 찌그러짐 → 공중에서 8~15% 늘어남 → 착지 때 다시 찌그러짐
    • 눈 깜빡임은 2프레임, 조명은 매 프레임 ±1~2% 깜빡
  • 재질·카메라·조명
    • 점토 거칠기 0.5~0.7, 반사 약 0.35, 서브서피스는 아주 조금(많으면 밀랍·젤리 같아요)
    • 표면에 지문 모양 요철 + 색 얼룩 ±10%
    • 50mm 렌즈, 조리개 f/3~5, 카메라는 고정
    • 노출 −0.45~−1.0 (밝으면 점토 색이 날아가요)
    • 따뜻한 키 조명(왼쪽 앞 위) + 차가운 보조광(1/10) + 뒤쪽 림 조명 + 실제 광원 하나(문틈 불빛, 스탠드)
  • 한 번에 고퀄로 바꾸는 문장
    룩 가이드 숫자대로 다시 맞춰줘: 12fps on twos, 인형에 0.2mm 꿈틀거림, 점프는 15% 스쿼시·10% 스트레치, 점토 거칠기 0.6·서브서피스 0.05, 50mm f/4 고정 카메라, 노출 -0.7, 키 조명 ±1.5% 깜빡임. 테스트 스틸 3장 먼저 보여줘.

이럴 땐 이렇게

troubleshooting

자주 막히는 부분을 모았어요

Q28편이랑 뭐가 달라요?
A

28편은 claude.ai 한 줄, Blender 공식 커넥터 등 "Claude가 Blender를 다루는 방법"을 소개했어요. 이번 편은 그중 점토 스킬 하나를 골라 설치 명령어, 내 캐릭터 프롬프트, 고퀄 숫자까지 끝까지 따라 하는 판이에요.

Q윈도우에서도 돼요?
A

돼요. Blender·ffmpeg·Claude Code 모두 윈도우를 지원하고, Cycles가 NVIDIA(CUDA·OptiX)나 AMD(HIP) 그래픽카드를 자동으로 써요. 경로 문제가 생기면 Claude에게 "Blender 설치 경로 찾아서 써줘"라고 하세요.

Q그래픽카드가 없으면요?
A

CPU로도 렌더는 돼요. 다만 오래 걸리니 해상도와 샘플을 절반으로 줄이고(예: 960x540, 샘플 40), 먼저 테스트 스틸로 확인하세요.

Q무료예요?
A

스킬(MIT 라이선스)·Blender·ffmpeg는 무료예요. Claude Code는 Pro 이상 요금제가 필요하고, 긴 작업이라 사용량을 꽤 써요.

Q음악·효과음도 넣어줘요?
A

스킬은 무음 영상을 만들어요. 원작자는 ElevenLabs Music으로 음악을 따로 만들었어요. CapCut 같은 편집 앱에서 음악을 붙여도 돼요.

Q만든 영상을 올려도 돼요?
A

내가 만든 캐릭터라면 자유롭게 올려도 돼요. 유명 캐릭터·로고·실존 인물은 개인 연습용으로만 쓰세요.

tips

  4. 4

용어 풀이

glossary

처음 보는 단어가 있다면

스킬
Claude에게 특정 작업 방법을 알려주는 설명서 + 도구 묶음. 폴더째 ~/.claude/skills에 넣으면 필요할 때 Claude가 꺼내 써요.
Claude Code
내 컴퓨터 터미널에서 돌아가는 Claude. 파일을 만들고 프로그램을 실행할 수 있어요.
비트 시트
영상을 프레임 번호로 나눈 장면 계획표. 예: 1~30 이글루 전경, 31~60 펭귄 등장.
on twos (12fps)
같은 그림을 2프레임씩 보여줘 1초에 12번만 바뀌게 하는 방식. 스톱모션 특유의 뚝뚝 끊기는 맛.
boil (꿈틀거림)
멈춰 있어도 인형이 살짝 흔들리는 효과. 애니메이터가 손으로 만진 느낌을 줘요.
스쿼시 & 스트레치
뛰기 전에 찌그러지고 공중에서 늘어나는 표현. 부피는 거의 그대로 유지해요.
Cycles
Blender의 사실적인 렌더 엔진. 빛을 계산해서 사진 같은 그림을 뽑아요.
콘택트 시트
영상의 여러 프레임을 한 장에 바둑판처럼 모은 이미지. 이야기 흐름을 한눈에 확인해요.
