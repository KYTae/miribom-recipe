method
01STEP 1

가사에 시간 붙이기

  • 노래를 들으며 가사 줄마다 시작 시간을 적어요. 대충 맞아도 괜찮아요.
  • 타이밍 정리 예시
    0:00 [intro]
0:12 첫 번째 가사 줄
0:18 두 번째 가사 줄
0:25 세 번째 가사 줄
  • TIP타이밍 적기가 귀찮으면 노래를 받아쓰는 AI(예: 클로바노트)로 시간과 함께 받아 적게 할 수 있어요.
  • 피할 것
    • 남의 노래를 허락 없이 쓰기 (공개하면 문제가 될 수 있어요)
    • 처음부터 노래 전체로 시작하기 — 앞부분 30초로 먼저 해보세요
02STEP 2

웹 챗봇에 가사 영상 요청

  • 가사 애니메이션 만들기
    아래 가사와 시간으로 뮤직비디오처럼 움직이는 가사 애니메이션 웹페이지를 HTML 파일 하나로 만들어줘. 내가 버튼으로 노래 파일(mp3)을 불러오면 시간에 맞춰 가사가 나오게. 가사 내용을 해석해서 줄마다 어울리는 배경 그래픽과 움직임을 코드로 그려줘. 분위기는 [몽환적인 시티팝].

[시간 + 가사 붙여넣기]
  • TIP마음에 드는 장면이 나오면 "후렴에서는 화면이 더 크게 터지게"처럼 구간별로 고쳐 달라고 하세요.
    1. 1Claude.ai나 ChatGPT에서 새 대화 열기
    2. 2프롬프트를 붙여넣고 [ ] 안의 분위기와 시간+가사를 내 것으로 바꾸기
    3. 3결과가 나오면 미리보기 창(Claude는 오른쪽 아티팩트 창, ChatGPT는 캔버스)에서 실행
    4. 4노래 불러오기 버튼으로 mp3를 넣고 재생해서 타이밍 확인
03STEP 3선택

원작 방식: 코딩 AI에 밤새 맡기기

  • 코딩 AI는 파일을 만들고 렌더링까지 오래 혼자 작업할 수 있어요. 참고 이미지·가사·노래를 한 폴더에 넣고 시작해요.
  • 긴 작업 요청
    In this folder there is a song (song.mp3), its lyrics with timestamps (lyrics.txt) and reference images (refs/). Create a brand-new music video for this song that expresses the lyrics as well as possible. Plan scenes per lyric line, design a consistent character, animate everything with code, and render a 1080p MP4 synced to the audio. Work autonomously, check your own output, and keep improving until it looks finished.
  • 주의오래 작업시키면 사용량·비용이 많이 들어요. 처음엔 30초 구간만 먼저 만들어 보게 하세요.
    1. 1새 폴더를 만들고 song.mp3, lyrics.txt, 참고 이미지 refs 폴더를 넣기
    2. 2그 폴더에서 Claude Code 실행
    3. 3아래 실전 프롬프트의 30초 시험판 먼저 요청
    4. 4마음에 들면 전체 곡으로 이어서 맡기기

Claude·ChatGPT 대화창 또는 Claude Code에 붙여넣으세요 · 미리봄이 만든 예시예요

01가사에 시간 붙이기 도우미
아래 가사를 가사 영상용으로 정리해줘.
- 노래 길이: [예: 2분 40초]
- 내가 아는 시간: [예: 첫 줄 0:12, 후렴 시작 0:45]
- 형식: 한 줄에 「0:12 가사」처럼 시간 + 가사
- 내가 모르는 줄은 앞뒤 시간을 보고 대략 채우고, 끝에 (추정)이라고 표시해줘
- 인트로·간주·후렴 구간은 [intro] [chorus]처럼 따로 표시

[가사 붙여넣기]

노래 들으며 몇 군데만 시간을 적고 나머지는 AI에게 — 추정 줄은 꼭 다시 들어보세요

02가사 해석 → 장면 계획표
이 노래로 뮤직비디오 장면 계획을 세워줘. 아직 코드는 만들지 마.
- 노래 분위기: [예: 몽환적인 시티팝, 밤 드라이브]
- 화면 비율: [세로 9:16 / 가로 16:9]
- 표로 정리: 시간 | 가사 | 화면에 나올 그림 | 색 | 움직임 | 글자 효과
- 후렴은 다른 구간보다 화면이 확실히 커지게 계획해줘
- 끝에 전체 영상의 색 3가지와 글꼴 느낌을 한 줄로 정리

[시간 + 가사 붙여넣기]

원작에서 AI가 한 「가사 해석·연출」 단계를 내가 먼저 확인하는 버전

03가사 영상 HTML — 내 노래 버전
아래 장면 계획표와 가사로 가사 애니메이션 웹페이지를 HTML 파일 하나로 만들어줘. 외부 파일 없이.
- 노래 불러오기 버튼(mp3) + 재생/일시정지 버튼
- 가사는 시간에 맞춰 한 줄씩 등장, 글꼴 느낌: [예: 두껍고 둥근 글씨]
- 배경 그래픽은 가사 뜻에 맞게 코드로 그리기, 메인 색: [예: 남색 + 분홍]
- 후렴 구간 [예: 0:45~1:10]은 글자를 크게, 박자마다 튀어나오게
- 화면 아래에 지금 시간을 작게 표시 (타이밍 고칠 때 보려고)

[장면 계획표 또는 시간 + 가사]

페이지 2단계 프롬프트를 바꿔 쓴 버전 · 장면 계획표를 먼저 만들었다면 같이 붙여넣기

04Claude Code — 30초 시험판 먼저
이 폴더에 노래(song.mp3), 시간이 붙은 가사(lyrics.txt), 참고 이미지(refs/)가 있어.
먼저 노래 앞부분 [30]초만 뮤직비디오로 만들어줘.
1) 시작 전에 장면 계획과 쓸 도구(설치가 필요한 프로그램 포함)를 목록으로 보여주고 내 OK를 기다려
2) 캐릭터는 [예: 분홍 젤리 같은 작은 생물] 하나로, 모든 장면에서 같은 모습 유지
3) 결과는 [1080x1920] MP4로 저장
4) 렌더링한 뒤 프레임 몇 장을 직접 확인하고, 가사 타이밍이 어긋나거나 글자가 잘리면 고쳐줘

원작 방식을 바로 하룻밤 맡기기 전에 — 짧게 시험해서 비용·방향 확인

05Claude Code — 밤새 맡기기 (전체 곡)
30초 시험판 방향이 좋아. 이제 같은 스타일로 노래 전체를 만들어줘.
- 작업 순서: 구간별로 나눠서 만들고, 구간마다 렌더링해 확인한 뒤 다음으로
- 진행 기록: progress.md 파일에 한 일·남은 일·문제점을 계속 적어줘
- 막히면 같은 시도를 반복하지 말고 다른 방법을 쓰고, 그래도 안 되면 기록에 남기고 다음 구간으로
- 꼭 지킬 것: [예: 캐릭터 색은 그대로, 가사 글자는 한국어 그대로]
- 마지막에 전체 MP4([파일 이름, 예: final.mp4])와 고칠 만한 부분 3가지를 알려줘

시험판이 마음에 들 때 이어서 · 오래 돌릴수록 사용량이 많이 들어요

06캐릭터 설정표 + 이미지 AI용 프롬프트
이 노래 뮤직비디오의 주인공 캐릭터 설정을 만들어줘.
- 노래 분위기: [예: 쓸쓸하지만 귀여운]
- 캐릭터 느낌: [예: 작은 로봇 / 동물 / 젤리]
1) 생김새·색·표정·옷을 표로 정리
2) 어떤 장면에서도 같은 모습이 나오게, 이미지 AI에 넣을 영어 프롬프트를 [3]개 써줘 (정면 / 옆모습 / 감정 표현)
3) 실존 인물이나 유명 캐릭터를 닮지 않게 해줘

원작처럼 캐릭터는 이미지 AI로 그릴 때 · 설정표를 Claude Code 폴더에 같이 넣어두면 좋아요

07Suno — 노래가 없을 때 스타일 문장
[genre, e.g. dreamy city pop], [mood, e.g. late-night drive, a little lonely], mid-tempo, warm synth pads, clean electric guitar, punchy drums, [vocal, e.g. soft female vocal], catchy chorus, clear Korean lyrics, 2 minutes

Suno에서 노래 스타일을 적는 칸에 붙여넣기 · [ ]에 장르·분위기·목소리를 영어로 · 가사는 Suno나 챗봇으로 따로 만들어도 돼요

08공개 전 점검표
내가 만든 AI 뮤직비디오를 [올릴 곳, 예: 인스타 릴스]에 올리려고 해.
- 노래 출처: [예: 내가 Suno로 만든 곡]
- 그림·캐릭터 출처: [예: 이미지 AI로 직접 만든 것]
올리기 전에 확인할 것을 체크리스트로 만들어줘. 저작권, AI로 만든 콘텐츠 표시, 캡션에 넣을 출처 문구를 꼭 포함하고, 확실하지 않은 건 「해당 플랫폼 안내를 확인하세요」라고 적어줘.

이럴 땐 이렇게

troubleshooting

자주 막히는 부분을 모았어요

Q아무 노래나 써도 돼요?
A

저작권이 있는 노래로 만든 영상을 공개하면 문제가 될 수 있어요. 내가 만든 곡(예: AI 작곡)이나 허락받은 곡을 쓰세요.

Q화면 왼쪽 위 P(doom) 숫자는 뭐예요?
A

"AI가 인류에 재앙이 될 확률"을 뜻하는 AI 업계 밈이에요. 영상이 진행될수록 숫자가 올라가는 연출이에요.

Q노래가 없어요
A

Suno 같은 노래 생성 AI로 1~2분 노래를 먼저 만들어보세요. 가사도 같이 만들어줘요.

Q가사 타이밍은 어떻게 알아요?
A

노래를 들으며 줄마다 시작 시간을 적거나, Suno에서 만든 노래라면 가사 영상을 함께 받아 Claude에게 보여주면 돼요.

Q더 자세한 방법이 있어요?
A

26번 레시피에 원작자 프롬프트 전문과 3가지 방법을 훨씬 자세히 정리했어요.

Q프롬프트는 어디에 붙여요?
A

쉬운 방법은 claude.ai나 chatgpt.com 대화창에 붙여넣으면 돼요. 원작 방식은 노래·가사 파일이 있는 폴더에서 Claude Code를 실행한 뒤 붙여넣어요.

QMP4 영상 파일로 저장하고 싶어요
A

웹 챗봇 결과는 브라우저에서 움직이는 웹페이지예요. 화면 녹화로 저장하거나, 파일로 바로 뽑고 싶으면 Claude Code 같은 코딩 AI 방식으로 해야 해요.

Q노래는 안 나오고 가사만 움직여요
A

노래 불러오기 버튼으로 mp3를 직접 넣어야 소리가 나요. 버튼이 없으면 「mp3 불러오기 버튼과 재생 버튼을 넣어줘」라고 이어서 보내세요.

Q폰으로도 돼요?
A
