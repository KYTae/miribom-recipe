게임 회사 없이 혼자 만든 농장 게임 — Opus 5.5 + Unity 6, 부서별 프롬프트 6단계 (영어 원문 그대로)

X의 @Mnilax는 Opus 5.5와 Unity 6로 혼자 아늑한 농장 게임을 만들고 그 방법을 6줄로 공개했어요(저장 1,200회 이상). 비결은 “게임 회사처럼, 부서마다 프롬프트 하나씩”. 모델은 Tripo, 세상과 물리는 Unity 6, 코드·장면·테스트는 Opus 5.5, 그리고 사람은 직접 해보고 어색한 걸 말하는 역할이에요. 원문 그대로 저장할 수 있게 영어 원문을 먼저 싣고, 단계마다 Claude Code에 바로 붙여 넣는 영어 프롬프트와 한국어 설명을 정리했어요.

  3. 3step 3 · 모델Tripo로 농부 · 헛간 · 풍차 · 작물 전부 생성
  4. 4step 4 · 정리와 배치Opus가 Blender에서 다듬고 Unity에 섬을 지음
  5. 5step 5 · 시스템프롬프트 하나에 시스템 하나: 심기, 성장 타이머, 시장, 코인
  6. 6step 6 · 테스트Opus가 자동 플레이로 테스트, 고치기 전에 버그 목록부터

원작자가 꼽은 핵심 규칙은 한 줄이에요 — “build one system, play it, then the next(시스템 하나 만들고, 해보고, 그다음).” 한 번에 게임 전체를 시키지 않고, 게임 회사의 부서처럼 일을 쪼개서 하나씩 끝내는 방식이에요. 버그도 바로 고치지 말고 목록부터 받는 게 포인트예요.

준비물

  • Claude CodeOpus 5.5를 쓸 수 있는 요금제. 터미널이나 데스크톱 앱에서 실행해요.
  • Unity 6 (무료 Personal)게임 세상·물리·화면(UI)을 담당해요. Unity Hub에서 설치해요.
  • Blender (무료)모델을 다듬는 데 써요. Blender MCP로 Claude가 직접 조작해요.
  • MCP 연결Claude Code가 Unity·Blender를 직접 만지게 해주는 연결 도구. 원작자는 어떤 Unity용 MCP를 썼는지는 밝히지 않았어요.
  • Tripo글이나 그림으로 3D 모델을 만들어주는 AI. 농부·헛간·풍차·작물 모델을 여기서 만들었어요.

01STEP 1원문

원문 그대로 — 6단계 + 역할 분담 (영어)

  • 원작자가 공개한 글 전문이에요. 저장해두고 그대로 보면서 따라 하면 돼요.
  • 영어 원문 (X @Mnilax)
    how i build a cozy farm game solo with Opus 5.5 and Unity 6

the trick is building it like a studio, one department per prompt:

step 1 -> connect Claude Code to Unity 6 and Blender through MCP
step 2 -> write a 1-page doc: plant > water > harvest > sell, 4 seasons
step 3 -> generate every model in Tripo: farmer, barn, windmill, crops
step 4 -> Opus cleans them in Blender and builds the island in Unity
step 5 -> one system per prompt: planting, growth timers, market, coins
step 6 -> Opus playtests with an autopilot and lists bugs before fixing any

who does what:

> tripo: every model
> unity 6: the world, physics, ui
> opus 5.5: scripts, scene setup, playtests
> you: play it and say what feels off

the rule that saves it... build one system, play it, then the next
    1. 1tripo = 모든 3D 모델
    2. 2unity 6 = 게임 세상 · 물리 · 화면(UI)
    3. 3opus 5.5 = 코드 · 장면 구성 · 플레이테스트
    4. 4you(나) = 직접 해보고 어색한 점 말하기
  • TIP“the rule that saves it” — 시스템 하나를 만들면 반드시 직접 해보고, 괜찮을 때만 다음으로 넘어가요. 한 번에 다 시키면 어디서 망가졌는지 찾기 어려워요.
02STEP 21·2단계

step 1~2 — 연결하고, 기획서는 딱 1장

  • 먼저 Claude Code가 Unity 6와 Blender를 직접 만질 수 있게 MCP로 연결해요. 연결이 됐는지부터 확인하고, 그다음 한 장짜리 기획서를 쓰게 해요. 핵심 루프는 심기 > 물 주기 > 수확 > 판매, 그리고 사계절.
  • step 1 · 연결 확인 (영어, 미리봄 예시)
    You are connected to Unity 6 and Blender through MCP.
Before writing any game code, check both connections:
1) In Unity, create an empty scene called "Farm_Test" and add one cube.
2) In Blender, list the objects in the open file.
Tell me what worked and what failed. Don't build anything else yet.
  • step 2 · 1-page doc (영어, 미리봄 예시)
    Write a 1-page game design doc for a cozy farm game. Keep it to one page.
Core loop: plant > water > harvest > sell.
4 seasons, each changes which crops can grow.
Include: player controls, 4 starter crops (growth time + sell price), the market, coins, and what "day 1" looks like.
No code yet. Ask me only if something is truly unclear.
  • TIP기획서를 “한 장”으로 제한하면 AI가 욕심내서 기능을 늘리지 않아요. 이 한 장이 이후 모든 프롬프트의 기준이 돼요.
03STEP 33·4단계

step 3~4 — Tripo로 모델, Opus가 다듬고 섬을 짓는다

  • 농부·헛간·풍차·작물 같은 모델은 Tripo로 전부 만들고, Opus가 Blender에서 크기·중심점·폴리곤을 정리한 뒤 Unity에 가져가 섬을 지어요.
  • step 3~4 · 정리와 배치 (영어, 미리봄 예시)
    Here are 3D models I generated in Tripo: farmer, barn, windmill, crops (4 growth stages each).
Clean them up in Blender: fix scale to real-world meters, center the origins at the base, reduce polycount for a mobile-friendly game, keep the cozy toon look.
Then import them into Unity 6 and build a small island scene: farm plot in the middle, barn, windmill, market stalls by the path, sea around it.
  • 정리할 때 꼭 시킬 것
    • 크기를 실제 미터 단위로 맞추기
    • 중심점(origin)을 바닥 가운데로
    • 폴리곤 줄이기
    • 같은 그림체(카툰 톤) 유지
04STEP 45·6단계

step 5~6 — 프롬프트 하나에 시스템 하나, 버그는 목록부터

  • 심기, 성장 타이머, 시장, 코인 — 시스템마다 프롬프트를 따로 써요. 하나 만들면 직접 해보고, 괜찮으면 다음. 마지막엔 Opus가 자동 플레이(오토파일럿)로 게임을 돌려보고, 고치기 전에 버그 목록부터 내놓게 해요.
  • step 5 · 시스템 하나만 (영어, 미리봄 예시)
    Build ONE system only: planting.
The player walks to a soil tile, presses E to plant a seed, and a sprout appears.
Write the script, hook it up in the scene, and tell me exactly how to test it.
Don't start growth timers, market, or coins until I say the planting feels right.
  • step 6 · 자동 플레이 테스트 (영어, 미리봄 예시)
    Playtest the game with an autopilot: write a simple bot that plays 10 in-game days (plant, water, harvest, sell).
Log everything that goes wrong.
Give me a numbered bug list first, sorted by how badly it breaks the game.
Do NOT fix anything until I pick which bugs to fix.
  • 주의버그를 바로 고치게 하면 하나 고치다 다른 걸 망가뜨리기 쉬워요. 목록 → 내가 고를 것 선택 → 하나씩 수정 순서로 가세요.

이럴 땐 이렇게

troubleshooting

자주 막히는 부분을 모았어요

Q진짜 게임이에요, AI 영상이에요?
A

원작자는 Opus 5.5와 Unity 6로 만든 게임이라고 밝혔고, 아직 “알파 버전”이라 이달 안에 공개해 보겠다고 답했어요. 직접 플레이할 수 있는 링크는 아직 없어요.

Q코딩을 몰라도 돼요?
A

코드는 Opus가 쓰지만, Unity·Blender 설치와 MCP 연결은 직접 해야 해요. 처음이라면 step 1 연결 확인부터 천천히 해보세요.

Q어떤 MCP를 썼어요?
A

원작자는 Unity·Blender를 MCP로 연결했다고만 밝혔어요. Blender는 Blender MCP, Unity는 Unity용 MCP 서버를 찾아 연결하면 돼요.

QTripo 말고 다른 걸 써도 돼요?
A

네. 3D 모델을 만들어주는 다른 AI 도구를 써도 흐름은 같아요. 다만 그림체가 섞이지 않게 한 도구로 통일하는 게 좋아요.
