AI가 몰래 받는 지시문, 직접 써먹는 법

ChatGPT·Claude 같은 AI는 내 질문을 읽기 전에 회사가 넣어둔 "시스템 프롬프트"부터 읽어요. 그건 못 바꾸지만, 설정에 "내 지시문"을 넣으면 모든 답이 내 취향에 맞춰져요. 복붙용 지시문과 넣는 위치를 정리했어요.

시스템 프롬프트가 뭐예요?

what is it

30초 요약

이렇게 작동해요

  1. 1회사 지시문시스템 프롬프트 (못 바꿈)
  2. 2내 지시문맞춤 지침 (내가 설정)
  3. 3내 질문매번 입력
  4. 4답변셋을 모두 반영

워싱턴포스트 분석에 따르면 시스템 프롬프트는 길게는 2만 7천 단어에 이르고, 대부분은 도구 사용법이에요. 우리가 바꿀 수 있는 건 가운데 "내 지시문"이에요. 한 번 넣어두면 모든 대화에 적용돼요.

준비물

  • ChatGPT설정 → 개인 맞춤 설정 → 맞춤형 지침
  • Claude설정 → 프로필(개인 선호 사항) 칸
  • Gemini설정 → 저장된 정보(내 정보·선호)
  • 참고메뉴 이름은 앱 버전에 따라 조금 달라요

복붙용 내 지시문

prompt pack

누르면 바로 복사돼요 · 상황별로 골라 쓰세요

릴스 속 4가지

하나만 골라도, 여러 개 이어 붙여도 돼요

01① 핵심만
항상 결론부터 한 문장으로 말하고, 필요할 때만 근거를 덧붙여줘.
02② 직설적으로
돌려 말하지 말고 직설적으로 말해줘. 불필요한 인사말과 칭찬은 빼줘.
03③ 맞장구 금지
내 말에 무조건 동의하지 말고, 틀린 점이나 빈틈이 있으면 먼저 지적해줘.
04④ 형식 정하기
설명은 3줄 이내로, 비교는 표로, 단계는 번호 목록으로 정리해줘.

상황별 완성 지시문

[ ] 부분만 나에게 맞게

05직장인용
나는 [마케팅팀 3년 차]야. 답은 결론 → 근거 → 바로 할 일 순서로, 보고서에 바로 붙일 수 있는 문장으로 써줘. 모르는 건 지어내지 말고 "확인 필요"라고 해줘. 숫자는 출처가 있을 때만 써줘.
06공부용
나는 [고등학생]이야. 개념은 쉬운 비유로 먼저 설명하고, 그다음 정확한 정의를 알려줘. 설명 끝에 이해했는지 확인하는 문제 1개를 내줘. 답을 바로 주지 말고 힌트부터 줘.
07글쓰기 코치
내 글을 고칠 땐 고친 문장과 이유를 표로 보여줘. 내 말투는 최대한 유지하고, 과장된 표현은 빼줘. 칭찬은 한 줄만.
08개발자용
코드는 설명보다 먼저 보여주고, 바뀐 부분만 diff처럼 표시해줘. 확실하지 않은 API는 추측하지 말고 공식 문서를 확인하라고 말해줘.

이럴 땐 이렇게

troubleshooting

자주 막히는 부분을 모았어요

Q넣었는데 가끔 안 지켜요
A

지시문이 길거나 서로 부딪히면 일부를 놓쳐요. 가장 중요한 것 3~4개로 줄여보세요.

Q회사 시스템 프롬프트를 볼 수 있어요?
A

Anthropic은 Claude의 핵심 지시문을 공개하고, OpenAI는 공개하지 않아요. 내 지시문이 회사 지시문보다 우선하진 않아요.

Q능력도 좋아지나요?
A

능력 자체는 그대로예요. 답의 말투·길이·형식이 내 취향에 맞춰질 뿐이에요.

Q어디에 넣어요?
A

ChatGPT: 설정 → 개인 맞춤 설정 → 맞춤형 지침 / Claude: 설정 → 프로필(개인 설정) / Gemini: 설정 → 저장된 정보·지침. 메뉴 이름은 업데이트로 조금씩 바뀔 수 있어요.

Q지시문을 여러 개 섞어도 돼요?
A

돼요. 다만 서로 반대되는 말(예: "길게"와 "핵심만")이 없게 정리하세요.

꿀팁

tips
  1. 1

    처음엔 2~3줄만 넣고 일주일 써본 뒤 불편한 점을 한 줄씩 추가하세요.

  2. 2

    업무용·개인용 지시문을 따로 쓰고 싶다면 "프로젝트"를 만들어 프로젝트마다 다른 지시문을 넣으세요.

  3. 3

    "맞장구 금지" 같은 지시문은 효과가 커요. 듣기 좋은 말만 나와서 답답했다면 꼭 넣어보세요.
