AI가 몰래 받는 지시문, 직접 써먹는 법

ChatGPT·Claude 같은 AI는 내 질문을 읽기 전에 회사가 넣어둔 "시스템 프롬프트"부터 읽어요. 그건 못 바꾸지만, 설정에 "내 지시문"을 넣으면 모든 답이 내 취향에 맞춰져요. 복붙용 지시문과 넣는 위치를 정리했어요.

시스템 프롬프트가 뭐예요?

what is it

30초 요약

이렇게 작동해요

  1. 1회사 지시문시스템 프롬프트 (못 바꿈)
  2. 2내 지시문맞춤 지침 (내가 설정)
  3. 3내 질문매번 입력
  4. 4답변셋을 모두 반영

워싱턴포스트 분석에 따르면 시스템 프롬프트는 길게는 2만 7천 단어에 이르고, 대부분은 도구 사용법이에요. 우리가 바꿀 수 있는 건 가운데 "내 지시문"이에요. 한 번 넣어두면 모든 대화에 적용돼요.

준비물

  • ChatGPT설정 → 개인 맞춤 설정 → 맞춤형 지침
  • Claude설정 → 프로필(개인 선호 사항) 칸
  • Gemini설정 → 저장된 정보(내 정보·선호)
  • 참고메뉴 이름은 앱 버전에 따라 조금 달라요

복붙용 내 지시문

prompt pack

누르면 바로 복사돼요 · 상황별로 골라 쓰세요

실전 프롬프트 — [ ]만 바꿔서 쓰기

ChatGPT·Claude·Gemini 대화창에 보내서 내 지시문을 만든 뒤 설정에 넣으세요 · 미리봄이 만든 예시예요

01인터뷰로 내 지시문 만들기
나에게 맞는 "맞춤 지침(내 지시문)"을 만들고 싶어. 설정 칸에 그대로 붙여넣을 거야.
나는 주로 [AI를 쓰는 일, 예: 회사 보고서 정리와 이메일 쓰기]에 AI를 써.
바로 쓰지 말고 먼저 나한테 질문 5개를 해줘 (답의 길이, 말투, 형식, 싫은 점, 내 배경 등).
내 답을 받으면
- 10줄 이내의 지시문으로 정리하고
- 서로 부딪히는 문장이 없는지 스스로 확인한 다음
- 복사하기 쉽게 코드 블록 하나에 넣어줘

처음 만들 때 — 무엇을 써야 할지 몰라도 돼요

02직업·상황 맞춤 지시문
아래 정보로 모든 대화에 적용할 내 지시문을 써줘.
- 나: [직업·상황, 예: 동네 카페 사장 / 대학원생 / 육아 중인 부모]
- AI에게 주로 맡기는 일: [예: 메뉴 소개 글, 손님 응대 문장, 가게 일정 정리]
- 답의 형식: [예: 결론 먼저, 3줄 요약, 비교는 표]
- 꼭 지켜줬으면 하는 것: [예: 모르는 건 지어내지 말기, 한국어 존댓말]
릴스 속 4가지(핵심만 · 직설적으로 · 맞장구 금지 · 형식 정하기) 중 나에게 맞는 것을 골라 섞고, 8줄 이내로 써줘.

릴스 속 상황별 지시문을 내 직업에 맞게 바꿔 쓰는 템플릿

03지금 넣은 지시문 점검받기
내가 설정에 넣어둔 지시문을 점검해줘.
[지금 넣어둔 지시문을 그대로 붙여넣기]
1) 서로 부딪히는 문장 (예: 길게 vs 핵심만)
2) 너무 모호해서 AI가 지키기 어려운 문장
3) 빼도 되는 문장
을 표로 보여주고, 고친 버전을 원래보다 짧게 다시 써줘. 내가 원래 원한 방향은 바꾸지 마.

넣었는데 잘 안 지킬 때 — 길이·충돌부터 점검

04프로젝트(작업 공간)용 지시문
[작업 이름, 예: 블로그 글쓰기] 전용 프로젝트에 넣을 지시문을 써줘.
- 목표: [예: 일주일에 2번 동네 맛집 리뷰 글 올리기]
- 독자: [예: 20~30대 동네 주민]
- 글 형식: [예: 제목 3안 → 본문 800자 → 해시태그 5개]
- 피할 것: 과장 광고 문구, 확인 안 된 정보
평소 쓰는 내 지시문과 겹치지 않게 이 작업에만 필요한 규칙만 8줄 이내로.

Claude·ChatGPT의 프로젝트 지시문 칸에 · 업무·개인을 나눌 때

05설정 없이 이번 대화만 적용
이번 대화에서만 아래 규칙을 지켜줘. 대화가 끝날 때까지 계속 적용해.
- 역할: [예: 깐깐한 면접관]
- 답 형식: [예: 질문 하나씩, 내 답을 듣고 점수 1~5와 고칠 점 1줄]
- 금지: 칭찬만 하기, 한 번에 여러 질문하기
규칙을 이해했으면 "준비됐어요" 한 줄만 답하고 첫 질문을 해줘.
주제: [예: 마케팅 신입 면접]

설정을 건드리기 싫거나 메뉴가 없을 때 — 대화 첫 메시지로

06지시문 효과 확인하기
내 지시문이 제대로 먹히는지 시험해보고 싶어.
내 지시문: [지시문을 붙여넣기]
이 지시문을 지키기 어려운 테스트 질문 5개를 만들어줘 (예: 길게 답하고 싶어지는 질문, 맞장구치고 싶어지는 질문).
각 질문 옆에 '지시문을 잘 지켰다면 답이 어떤 모습이어야 하는지' 한 줄로 적어줘.

새 대화를 열어 테스트 질문을 하나씩 던져보세요

07맞장구 금지 — 사실 확인 강화판
앞으로 내 말에 쉽게 동의하지 마. 대신 이렇게 답해줘.
- 내 말에서 사실과 다를 수 있는 부분을 먼저 짚기
- 내 계획이면 가장 큰 위험 1개와 대안 1개
- 확실하지 않은 건 "확인 필요"라고 표시하고, 숫자·날짜는 출처가 있을 때만
- 칭찬은 [예: 꼭 필요할 때 한 줄만]
내가 주로 상의하는 일: [예: 창업 아이디어, 투자 결정]

릴스 속 4가지

하나만 골라도, 여러 개 이어 붙여도 돼요

14① 핵심만
항상 결론부터 한 문장으로 말하고, 필요할 때만 근거를 덧붙여줘.
15② 직설적으로
돌려 말하지 말고 직설적으로 말해줘. 불필요한 인사말과 칭찬은 빼줘.
16③ 맞장구 금지
내 말에 무조건 동의하지 말고, 틀린 점이나 빈틈이 있으면 먼저 지적해줘.
17④ 형식 정하기
설명은 3줄 이내로, 비교는 표로, 단계는 번호 목록으로 정리해줘.

상황별 완성 지시문

[ ] 부분만 나에게 맞게

18직장인용
나는 [마케팅팀 3년 차]야. 답은 결론 → 근거 → 바로 할 일 순서로, 보고서에 바로 붙일 수 있는 문장으로 써줘. 모르는 건 지어내지 말고 "확인 필요"라고 해줘. 숫자는 출처가 있을 때만 써줘.
19공부용
나는 [고등학생]이야. 개념은 쉬운 비유로 먼저 설명하고, 그다음 정확한 정의를 알려줘. 설명 끝에 이해했는지 확인하는 문제 1개를 내줘. 답을 바로 주지 말고 힌트부터 줘.
20글쓰기 코치
내 글을 고칠 땐 고친 문장과 이유를 표로 보여줘. 내 말투는 최대한 유지하고, 과장된 표현은 빼줘. 칭찬은 한 줄만.
21개발자용
코드는 설명보다 먼저 보여주고, 바뀐 부분만 diff처럼 표시해줘. 확실하지 않은 API는 추측하지 말고 공식 문서를 확인하라고 말해줘.

5분 맛보기 — 한 줄만 넣어보기

easy way

설정 메뉴 하나, 문장 한 줄

  • 준비물에 적힌 위치(ChatGPT·Claude·Gemini 설정)에서 내 지시문 칸을 찾아요
  • 아래 한 줄을 붙여넣고 저장해요
  • 새 대화를 열어 평소 하던 질문을 해보고 답이 어떻게 달라졌는지 봐요
딱 한 줄 지시문
답은 결론 한 문장으로 시작하고, 전체를 5줄 이내로 써줘. 모르는 건 지어내지 말고 확인 필요라고 말해줘.

이럴 땐 이렇게

troubleshooting

자주 막히는 부분을 모았어요

Q넣었는데 가끔 안 지켜요
A

지시문이 길거나 서로 부딪히면 일부를 놓쳐요. 가장 중요한 것 3~4개로 줄여보세요.

Q회사 시스템 프롬프트를 볼 수 있어요?
A

Anthropic은 Claude의 핵심 지시문을 공개하고, OpenAI는 공개하지 않아요. 내 지시문이 회사 지시문보다 우선하진 않아요.

Q능력도 좋아지나요?
A

능력 자체는 그대로예요. 답의 말투·길이·형식이 내 취향에 맞춰질 뿐이에요.

Q어디에 넣어요?
A

ChatGPT: 설정 → 개인 맞춤 설정 → 맞춤형 지침 / Claude: 설정 → 프로필(개인 설정) / Gemini: 설정 → 저장된 정보·지침. 메뉴 이름은 업데이트로 조금씩 바뀔 수 있어요.

Q지시문을 여러 개 섞어도 돼요?
A

돼요. 다만 서로 반대되는 말(예: "길게"와 "핵심만")이 없게 정리하세요.

Q무료 계정에서도 돼요?
A

서비스·요금제마다 다를 수 있어요. 설정 화면에서 메뉴가 보이는지 확인하고, 없으면 대화 첫 메시지로 지시문을 보내도 그 대화에선 효과가 있어요.

Q지시문을 바꿨는데 예전처럼 답해요
A

이미 진행 중인 대화엔 바로 반영되지 않을 수 있어요. 새 대화를 열어서 확인해보세요.

Q개인 정보를 넣어도 괜찮아요?
A

직업·말투 정도면 충분해요. 주민번호, 계좌, 비밀번호 같은 민감한 정보는 넣지 마세요.

꿀팁

tips
  1. 1

    처음엔 2~3줄만 넣고 일주일 써본 뒤 불편한 점을 한 줄씩 추가하세요.

  2. 2

    업무용·개인용 지시문을 따로 쓰고 싶다면 "프로젝트"를 만들어 프로젝트마다 다른 지시문을 넣으세요.

  3. 3

    "맞장구 금지" 같은 지시문은 효과가 커요. 듣기 좋은 말만 나와서 답답했다면 꼭 넣어보세요.

  4. 4

    지시문을 바꾼 뒤엔 새 대화를 열어서 확인하세요. 같은 질문을 던져 예전 답과 비교하면 효과가 바로 보여요.

  5. 5

    "적당히", "잘"보다 "3줄", "표로"처럼 숫자·형식으로 쓰면 훨씬 잘 지켜요.

맞춤 지침

개인 맞춤 설정
내 직업·말투 선호를 저장해 모든 대화에 적용하는 설정 메뉴.

AI에게 어떻게 답할지 알려주는 문장. 회사가 넣는 것(시스템 프롬프트)과 내가 넣는 것(맞춤 지침)이 있어요.
맞장구
상대 말에 무조건 맞다고 해주는 것. AI는 이 경향이 있어서 지시문으로 줄일 수 있어요.
