클로드, 아이클레이 장인 됐다 — 프롬프트 한 줄로 점토 애니·3D 장면 만들기 (Claude + Blender)

Claude Opus 5.5가 Blender(무료 3D 프로그램)를 직접 다루기 시작했어요. Anthropic의 Alex Albert는 claude.ai 대화창에 "Claude 로고가 주인공인 스톱모션 애니 만들어줘" 한 줄을 넣었는데, Claude가 점토 세트와 캐릭터를 만들고 렌더하고 프레임까지 검수해서 20초 애니를 돌려줬어요(조회 26.5만). 같은 방식으로 동화 속 성과 불꽃놀이(47만), 1906년 샌프란시스코 거리(15.8만)까지 나왔어요. 3D를 한 번도 안 해본 사람도 따라 할 수 있게 방법 3가지, 준비물, 프롬프트 전문을 정리했어요.

how it works

모델링·조명·애니메이션을 Claude가 코드로 하고, 나는 "어떤 장면인지"만 말해요

이렇게 작동해요

  1. 1장면 설명주인공·배경·이야기·느낌 한 문단
  2. 2Claude + BlenderPython 코드로 모델·재질·조명·카메라 생성
  3. 3스스로 검수테스트 프레임 렌더 → 확인 → 수정
  4. 4완성 영상mp4로 받고, 말로 고치기

Blender는 무료 3D 프로그램인데, 안에 Python이라는 코드로 거의 모든 걸 조작할 수 있어요. Claude는 이 코드를 써서 점토 캐릭터, 책상 세트, 조명, 카메라를 만들고 렌더(그림으로 뽑기)까지 해요. 그리고 뽑은 프레임을 직접 보고 "그림자가 이상하네" 하며 고쳐요. 나는 장면을 말로 설명하고, 결과를 보고 고칠 점만 말하면 돼요.

준비물

  • ClaudeOpus 5.5를 쓸 수 있는 요금제. 원본 영상(방법 A)은 claude.ai에서 프롬프트 한 줄로 만들었어요.
  • Blender (방법 B·C)blender.org에서 무료로 설치. 공식 Blender 커넥터(방법 B)는 Blender 5.1 이상이 필요해요. 점토 스킬(방법 C)은 4.2 이상(5.2에서 테스트).
  • Claude 데스크톱 앱 (방법 B)claude.com에서 설치. Blender 공식 커넥터를 연결해서 Claude가 열려 있는 Blender를 직접 조작해요.
  • Claude Code + ffmpeg (방법 C)컴퓨터에 설치하는 Claude와 영상 합치는 무료 도구 ffmpeg. 점토 스킬을 넣으면 한 줄로 애니가 나와요.
  • 컴퓨터·시간렌더는 그래픽카드가 있으면 훨씬 빨라요. 점토 스킬 기준 M4 Pro 맥에서 20초 영상 렌더 약 25분, 성 장면은 Opus 5.5가 약 35분 걸렸어요.

01STEP 1추천

방법 A · claude.ai에 한 줄 (원본 영상 방식)

  • Alex Albert는
    Opus 5.5가 이제 claude.ai에서 프롬프트 하나로 Blender를 써서 클레이메이션을 만든다
    1. 1claude.ai 접속 → 모델을 Opus 5.5로 선택
    2. 2아래 원본 프롬프트(영어)나 한국어 번역을 붙여넣기 — "Claude 로고" 자리를 내 캐릭터로 바꿔도 돼요
    3. 3작업이 끝날 때까지 기다리기 (중간 진행 상황을 Claude가 알려줘요)
    4. 4오른쪽에 뜨는 영상 확인 → 고칠 점을 말로 전하기
  • 원본 프롬프트 (영상 속 실제 문장, 영어)
    can you create a stop motion animation video (~20 seconds)? I want it to be super high quality and realistic looking like a professional animation studio made it. use the claude logo as the main character
  • 같은 내용 한국어
    20초 정도 되는 스톱모션 애니메이션 영상을 만들어줄 수 있어? 프로 애니메이션 스튜디오가 만든 것처럼 아주 고퀄리티에 실감 나게. 주인공은 Claude 로고로 해줘.
  • 이렇게 쓰면 잘 나와요
    • 길이(초), 화질 기준("프로 스튜디오처럼"), 주인공을 한 문장에
    • 주인공을 구체적으로: "주황색 점토 고양이", "파란 우비 입은 달팽이"
    • 마음에 들면 "같은 세트로 2편 만들어줘"
  • TIP원작자는 프롬프트 한 줄만 넣었어요. 이야기·조명·카메라를 더 정하고 싶으면 아래 "미리봄 점토 애니 프롬프트"를 쓰세요.
02STEP 2방법 B

방법 B · Claude 데스크톱 + Blender 공식 커넥터

  • Blender 재단의 Blender Lab이 공식 MCP 서버(커넥터)를 내놨고, Claude 커넥터 디렉터리에도 Blender가 있어요. 연결하면 Claude가 내 컴퓨터에 열린 Blender를 직접 조작해요. Stefan은 이렇게 "프롬프트 하나, Blender만, 전부 절차적으로" 성과 불꽃놀이 장면을 만들었는데 Opus 5.5가 35분, 출력 토큰 약 20만(API 기준 약 $13.3) 들었다고 해요.
    1. 1blender.org에서 Blender 5.1 이상 설치
    2. 2Blender Lab MCP 서버 페이지에서 애드온을 받아 Blender에 설치 (파일을 Blender 창에 끌어다 놓거나, 편집 → 환경설정 → 애드온 → 디스크에서 설치)
    3. 3Claude 데스크톱 앱 → 커넥터 디렉터리에서 Blender 추가 (또는 페이지의 MCP 번들 파일로 설치)
    4. 4Blender를 켜둔 채 Claude에 장면 프롬프트 붙여넣기
    5. 5중간중간 Blender 화면을 보면서 "탑을 더 높게"처럼 말로 고치기
  • 동화 속 성 + 불꽃놀이 (미리봄 예시, 한국어)
    Blender만 써서, 전부 절차적(코드)으로 이 장면을 만들어줘. 내려받은 모델·텍스처는 쓰지 마.

[장면]
밤의 산속 호수 한가운데 작은 섬 위에 동화 속 성. 뾰족한 첨탑 여러 개, 창문마다 따뜻한 불빛, 성 앞에 아치형 돌다리. 호수에는 성과 불꽃이 거울처럼 비치고, 뒤로는 겹겹이 산 실루엣. 하늘에서 별똥별 하나가 성 위로 큰 호를 그리며 지나가고, 이어서 불꽃놀이가 터져.

[결과물]
- 10초짜리 영상 1개 (1920x1080, 카메라는 천천히 앞으로)
- 만드는 과정 타임랩스: 단계마다 같은 각도로 스크린샷을 남겨서 마지막에 이어 붙여줘

[진행 방식]
지형 → 성 → 조명 → 물·반사 → 불꽃 순서로 만들고, 단계마다 렌더해서 직접 확인하고 고쳐.
  • 주의Blender MCP는 AI가 만든 코드를 그대로 실행해요. 공식 안내도 가상 머신이나 중요한 자료가 없는 컴퓨터에서 쓰라고 권해요. 작업 중인 중요한 .blend 파일은 미리 복사해 두세요.

방법 C · Claude Code + 오픈소스 점토 스킬

  • Miguel(@angrypenguinPNG)이
    Opus 5.5는 프롬프트 하나로 Blender에서 클레이메이션을 만든다
    1. 1Blender(4.2 이상)와 ffmpeg 설치 — 맥은 brew install --cask blender, 리눅스는 snap install blender --classic

    5. 5렌더가 끝나면 받은 mp4 확인 → 고칠 점 말하기
  • 스킬 README 예시 (영어 원문)
    can you make a stop motion claymation video (~20 seconds) of a little penguin who lives in an igloo?
  • 미리봄 점토 애니 프롬프트 (한국어)
    20초짜리 스톱모션 클레이 애니메이션을 Blender로 만들어줘.

[이야기 한 문단]
(아침 햇살이 드는 책상) 위에서 (주황색 점토 고양이)가 (머그컵 안에서) 깨어나, (기지개를 켜고 → 연필꽂이를 넘어뜨리고 → 놀라서 굴러다니다 → 책 위에 올라가 뿌듯하게 앉는) 이야기야. 대사는 없고 표정과 몸짓으로만.

[보이는 느낌]
- 진짜 점토: 손자국·지문, 살짝 울퉁불퉁한 표면, 부드러운 광택
- 책상 위 미니어처 세트: 나무 책상, 소품 3~4개, 뒤쪽 벽은 흐린 보케 조명
- 따뜻한 키 라이트 + 부드러운 그림자, 얕은 피사계 심도
- 카메라: 와이드 → 미디엄 → 클로즈업, 컷마다 고정(삼각대 느낌)

[움직임]
- 12fps "on twos"로 움직이고, 멈춰 있을 때도 표면이 살짝 꿈틀(boil)대게
- 등장·점프는 스쿼시 & 스트레치

[진행 방식]
1) 먼저 장면 3~5개로 나눈 비트 시트를 보여줘.
2) 모델·재질·조명·카메라를 전부 Blender Python으로 만들어. 다운로드한 모델은 쓰지 마.
3) 장면마다 테스트 프레임을 렌더해서 직접 확인하고 고쳐.
4) Cycles로 1920x1080 렌더 → mp4로 합쳐서 보내줘.
  • TIPGPU가 없으면 먼저 "960x540, 테스트 프레임 1장만" 렌더해서 느낌을 확인하고, 마음에 들 때 전체를 렌더하세요. 시간이 크게 줄어요.
04STEP 4응용

응용 · 자료 조사부터 하는 "고증" 장면

  • Alex Albert는
    모델링과 시각 능력이 좋아져서 프롬프트 하나로 세계 전체를 만들 수 있다
    1. 1방법 B나 C처럼 Claude가 Blender를 다룰 수 있게 준비
    2. 2아래 프롬프트를 내 동네·시대로 바꾸기 (예: 1960년대 종로, 내 학교 운동장)
    3. 3"자료 파일부터 보여줘"라고 해서 출처가 맞는지 먼저 확인
    4. 4확인 후 모델링·영상 진행
  • 1906 샌프란시스코 (원작자 공개 프롬프트, 영어)
    Recreate Market Street, San Francisco as it stood on April 17, 1906, the afternoon before the earthquake, in Blender.

Scope: the Ferry Building up Market to Fifth Street, including the Palace Hotel, the Call Building, the Chronicle Building, Lotta's Fountain and the Emporium.

Before modeling anything, build a source file from: the 1899-1905 Sanborn fire insurance maps (footprints, heights, materials, occupants), the Miles Brothers film "A Trip Down Market Street" (April 1906), period photographs from OpenSFHistory, the Library of Congress and the David Rumsey collection, and USGS topography. Record every building with footprint, height, facade material, occupant, and the source for each fact with a confidence level.

Build everything in Blender Python. No downloaded meshes, textures or HDRIs. Write reusable generators (Victorian commercial facade, mansard roof, bay windows, awnings, painted signage, gas and electric street lamps, cable car, horse-drawn wagon, early automobile) and assemble the street from the source file, so every building traces back to data.

Provide a 10 second video up the street.
  • 같은 내용 한국어
    1906년 4월 17일, 대지진 전날 오후의 샌프란시스코 마켓 스트리트를 Blender로 재현해줘.

범위: 페리 빌딩부터 마켓 스트리트를 따라 5번가까지. 팰리스 호텔, 콜 빌딩, 크로니클 빌딩, 로타의 분수, 엠포리움 포함.

모델링 전에 먼저 자료 파일을 만들어: 1899~1905년 샌본 화재보험 지도(건물 바닥 모양·높이·재료·입주자), 마일스 형제의 1906년 4월 영상 "A Trip Down Market Street", OpenSFHistory·미국 의회도서관·데이비드 럼지 컬렉션의 당시 사진, USGS 지형 자료. 건물마다 바닥 모양, 높이, 외벽 재료, 입주자, 그리고 각 사실의 출처와 확신도를 기록해.

전부 Blender Python으로 만들어. 내려받은 메시·텍스처·HDRI는 쓰지 마. 재사용할 수 있는 생성기(빅토리아풍 상가 정면, 맨사드 지붕, 돌출창, 차양, 손으로 칠한 간판, 가스·전기 가로등, 케이블카, 마차, 초기 자동차)를 만들고, 자료 파일을 바탕으로 거리를 조립해서 모든 건물이 데이터로 추적되게 해.

거리를 따라 올라가는 10초 영상으로 줘.
  • TIP"다운로드한 메시·텍스처·HDRI 금지"를 넣으면 모든 걸 코드로 만들어서, 나중에 "가로등을 전부 전기식으로" 같은 수정이 한 번에 돼요.

01미리봄 점토 애니 (영어)
Make a ~20 second stop-motion claymation film in Blender.

Story in one paragraph: on a (sunny morning desk), a (little orange clay cat) wakes up (inside a mug), (stretches → knocks over the pencil cup → rolls around in surprise → climbs onto a stack of books and sits proudly). No dialogue, only expressions and body language.

Look: real plasticine with thumbprints and slightly lumpy surfaces, soft sheen; a tabletop miniature set (wooden desk, 3-4 props, blurry bokeh lights on the back wall); warm key light, soft shadows, shallow depth of field; locked-off tripod shots, wide → medium → close-up.

Motion: animate on twos at 12 fps with a subtle boil even on held poses; squash and stretch on entrances and hops.

Process: 1) show a 3-5 beat sheet first. 2) build every model, material, light and camera in Blender Python, no downloaded assets. 3) render test frames for each beat, check them yourself and fix problems. 4) render 1920x1080 with Cycles and give me an mp4.

이럴 땐 이렇게

troubleshooting

자주 막히는 부분을 모았어요

Q3D를 한 번도 안 해봤는데 돼요?
A

돼요. 모델링·조명·애니메이션은 Claude가 코드로 해요. 방법 A는 Blender 설치도 필요 없어요. 나는 장면을 말로 설명하고 결과를 보고 고칠 점만 말하면 돼요.

Q무료로 돼요?
A

Blender와 점토 스킬은 무료예요. 다만 Claude는 Opus 5.5를 쓸 수 있는 요금제가 필요하고, 긴 작업은 사용량을 많이 써요. 성 장면은 API 기준 약 $13이 들었다고 해요.

Q시간은 얼마나 걸려요?
A

장면 만들기 15~35분, 렌더는 컴퓨터에 따라 달라요. 점토 스킬 기준 M4 Pro 맥에서 20초 영상 렌더가 약 25분이에요. 먼저 테스트 프레임만 뽑아 보세요.

QBlender 공식 커넥터가 연결이 안 돼요
A

Blender 버전이 5.1 이상인지, 애드온이 켜져 있는지, Blender를 켜둔 상태인지 확인하세요. 그래도 안 되면 Claude 데스크톱 앱을 완전히 껐다 켜세요.

QClaude 로고나 유명 캐릭터를 써도 돼요?
A

개인 연습은 괜찮지만, 남의 로고·캐릭터를 쓴 영상을 상업적으로 쓰면 문제가 될 수 있어요. 공개할 영상은 내 캐릭터로 만드세요.

Q만든 3D 파일을 계속 고칠 수 있어요?
A

방법 B·C는 .blend 파일과 Python 코드가 남아서 Blender에서 직접 열어 고치거나, Claude에게 이어서 수정을 시킬 수 있어요.

용어 풀이

glossary

처음 보는 단어가 있다면

Blender
무료 3D 프로그램. 모델링·애니메이션·렌더까지 다 돼요. Python 코드로 조작할 수 있어서 Claude가 다루기 좋아요.
클레이메이션
점토 인형을 조금씩 움직이며 한 장씩 찍는 스톱모션 애니메이션. 월레스와 그로밋 같은 느낌.
on twos (12fps)
같은 그림을 2프레임씩 보여줘서 1초에 12번만 바뀌게 하는 방식. 스톱모션 특유의 뚝뚝 끊기는 맛이 나요.
boil (꿈틀거림)
멈춰 있어도 표면이 살짝 흔들리는 효과. 손으로 만진 점토 느낌을 줘요.
렌더 / Cycles
3D 장면을 사진처럼 계산해서 그림으로 뽑는 과정. Cycles는 Blender의 사실적인 렌더 엔진이에요.
MCP / 커넥터
AI가 다른 프로그램(Blender 등)을 직접 조작하게 해주는 연결 방식. Claude에서는 "커넥터"로 추가해요.
스킬
Claude에게 특정 작업 방법을 알려주는 설명서·도구 묶음. 폴더째 넣으면 Claude가 필요할 때 꺼내 써요.
절차적 생성
모델을 손으로 만들지 않고 규칙(코드)으로 만드는 방법. 고치고 싶을 때 숫자만 바꾸면 돼요.
