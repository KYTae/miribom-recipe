ChatGPT에서 Higgsfield로 영상·게임 만드는 법

9월 30일 나온 ChatGPT용 Higgsfield 확장이에요. 채팅창에 슬래시(/) 명령어만 치면 영상·광고·게임까지 만들 수 있어요. 2026년 10월 기준이에요.

시작 전에

before you start

처음이라면 여기부터 읽어보세요

이렇게 작동해요

  1. 1ChatGPT에 Higgsfield 연결앱(커넥터)에서 추가
  2. 2채팅창에 / 입력명령어 고르기
  3. 3바꿀 내용 적기영상·사진 첨부 + 설명
  4. 4결과 받기Higgsfield 크레딧 사용

ChatGPT 대화창 안에서 Higgsfield를 불러 쓰는 방식이에요. 명령어(/genjutsu 등)를 고르고, 무엇을 무엇으로 바꿀지 문장으로 적으면 Higgsfield가 영상을 만들어 대화창에 돌려줘요.

준비물

  • ChatGPT 계정앱·커넥터 메뉴에서 Higgsfield를 추가해요 (화면 메뉴 이름은 계정마다 조금 달라요)
  • Higgsfield 계정연결할 때 로그인. 영상 생성은 Higgsfield 크레딧이 차감돼요
  • 바꿀 영상·사진/genjutsu는 직접 찍은 영상, /product는 제품 사진
  • 짧은 테스트용 클립처음엔 3~5초로 크레딧 아끼기

프롬프트 8개

prompt pack

누르면 바로 복사돼요 · 상황별로 골라 쓰세요

/genjutsu — 촬영본을 다른 장면으로

영상을 첨부하고 명령어 뒤에 붙여넣기

01그린스크린 → 판타지
/genjutsu 첨부한 영상의 움직임과 카메라는 그대로 두고 바꿔줘: 초록 배경 → 안개 낀 절벽 계곡, 배우 → 은색 갑옷을 입은 기사, 매트리스 → 거인의 손바닥. 조명은 해 질 녘 역광, 영화 같은 질감.

릴스에 나온 예시

02방 → 우주선
/genjutsu 영상 속 사람의 움직임은 그대로, 배경만 바꿔줘: 내 방 → 창밖으로 지구가 보이는 우주선 조종실. 옷은 흰 우주복으로. 카메라 움직임과 타이밍은 원본 그대로.
03사람 → 캐릭터
/genjutsu 영상 속 사람을 3D 애니메이션 스타일의 귀여운 너구리 캐릭터로 바꿔줘. 동작·표정·카메라는 원본 그대로, 배경은 원본 유지.

다른 명령어

채팅창에 / 를 치면 목록이 떠요

04/product — 제품 광고
/product 첨부한 제품 사진으로 9:16 세로 광고 영상을 만들어줘. 흰 대리석 위에서 제품이 천천히 회전하고, 물방울이 튀며, 마지막에 제품이 정면으로 멈춰요. 고급스러운 스튜디오 조명, 8초.
05/effects — 바이럴 이펙트
/effects 첨부한 사진 속 인물이 손가락을 튕기면 주변이 벚꽃잎으로 흩날리며 배경이 바뀌는 이펙트를 넣어줘. 9:16, 5초.
06/motion — 모션그래픽
/motion "미리봄 레시피" 글자가 핑크(#FF3BA0) 픽셀 조각으로 모였다가 반짝이며 완성되는 5초 로고 애니메이션. 검은 배경, 9:16.
07/marketing-studio — 마케팅 소재
/marketing-studio 홈카페 원두 브랜드의 인스타 광고 소재를 만들어줘. 타깃은 20~30대 직장인, 톤은 따뜻하고 미니멀. 세로 영상 1개와 정사각 이미지 3장.
08/games — 게임
/games 사무라이가 대나무 숲에서 몰려오는 닌자를 피하며 베는 간단한 2D 횡스크롤 게임. 방향키로 이동, 스페이스로 공격, 점수 표시, 3번 맞으면 게임 오버.

문장으로 규칙까지 적어요

이렇게 써요

method

릴스에 나온 두 가지 예시

01STEP 1

/genjutsu — 촬영본을 다른 장면으로

  • 촬영한 영상을 올리고 /genjutsu 입력
  • 바꿀 것을 하나씩 적기: 그린스크린 → 절벽 계곡, 배우 → 갑옷 기사, 매트리스 → 거인 손바닥
  • 사물·장소·캐릭터가 바뀌고 움직임은 그대로 남아요
  • 위가 실제 촬영본, 아래가 AI 결과
02STEP 2

결과는 이렇게 나와요

  • 매트리스 위에 누운 배우가 거인 손바닥 위의 기사로
  • 카메라 움직임과 몸짓은 촬영본 그대로
  • 짧게 먼저 만들어보고 마음에 들면 길게
03STEP 3

/games — 게임까지

  • 만들고 싶은 게임을 문장으로 설명
  • 영상 속 사무라이 게임은 Higgsfield Games로 만든 결과
  • 위는 Claude Opus 5.5, 아래는 GPT-6 Astra로 만든 버전

이럴 땐 이렇게

troubleshooting

자주 막히는 부분을 모았어요

Q채팅창에 / 를 쳐도 명령어가 안 떠요
A

ChatGPT에 Higgsfield가 아직 연결되지 않은 거예요. 앱(커넥터) 메뉴에서 Higgsfield를 추가하고 로그인한 뒤 새 채팅에서 다시 해보세요.

Q크레딧은 어디서 나가요?
A

ChatGPT 요금이 아니라 연결한 Higgsfield 계정의 크레딧이 차감돼요. 길이·화질이 클수록 많이 들어요.

Q움직임까지 바뀌어버려요
A

"움직임·카메라·타이밍은 원본 그대로"를 꼭 적고, 바꿀 대상을 "A → B" 형식으로 하나씩 나열하세요.

Q결과가 원하는 것과 달라요
A

바꿀 것을 한 번에 너무 많이 적으면 섞여요. 배경 하나만 먼저 바꿔보고, 마음에 들면 인물·소품을 추가하세요.
