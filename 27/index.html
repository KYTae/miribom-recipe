게임 개발자들 이거 보면 긴장할걸요 — Claude로 게임 만드는 법

Claude Opus 5.5로 만든 게임 영상들이 X에서 줄줄이 터졌어요. 설치 없이 웹에서 도시를 날아다니는 3D 게임(조회 183만), 보스전까지 있는 다크소울풍 액션 RPG(60만), 필살기 연출까지 있는 로블록스 대전 게임(46만). 셋 다 사람이 코드를 짠 게 아니라, 무엇을 만들지 말로 설명하고 결과를 보면서 고쳐 나갔어요. 처음 해보는 사람도 그대로 따라 할 수 있게 준비물, 연결 순서, 프롬프트 전문을 정리했어요.

how it works

코드는 Claude가 쓰고, 나는 "무엇을 만들지"와 "어디가 이상한지"만 말해요

이렇게 작동해요

  1. 1게임 설명장르·조작·분위기·목표 한 문단
  2. 2Claude Code코드·모델·텍스처를 직접 만들고 실행
  3. 3스스로 점검실행 → 스크린샷 → 수정 반복
  4. 4내가 플레이고칠 점을 말로 전하기

Claude Code는 내 컴퓨터에서 파일을 만들고 프로그램을 실행할 수 있는 Claude예요. 게임을 한 문단으로 설명하면 코드를 짜고, 3D 모델은 Blender 스크립트로, 텍스처는 이미지 생성으로 만들고, 직접 실행해서 화면을 확인하며 고쳐요. 로블록스는 스튜디오에 들어 있는 MCP 연결 기능으로 Claude가 스튜디오를 직접 조작해요. 나는 해보고 "점프가 너무 낮아"처럼 말만 하면 돼요.

준비물

  • ClaudeOpus 5.5를 쓸 수 있는 요금제. 게임처럼 오래 걸리는 작업은 Claude Code + Max 요금제가 편해요. 맛보기는 Claude 앱(웹)만으로도 돼요(아래 "가장 쉬운 방법").
  • Claude Code컴퓨터에 설치하는 Claude. 공식 안내 페이지의 설치 방법을 따라 설치하고, 게임용 빈 폴더를 하나 만들어 그 폴더에서 실행해요.
  • 웹 게임 (방법 A·C)Node.js(20 이상)와 크롬 같은 최신 브라우저. 3D 모델까지 만들려면 Blender(무료)를 설치해 두면 Claude가 스크립트로 써요. 그래픽카드가 있는 컴퓨터가 쾌적해요.
  • 로블록스 (방법 B)최신 로블록스 스튜디오(무료) + 로블록스 계정. 스튜디오 안의 MCP 서버로 Claude Code를 연결해요.
  • 시간첫 플레이 가능한 버전까지 30분~2시간. 원작처럼 다듬으려면 며칠에 걸쳐 여러 번 고쳐요(스파이더맨은 3번째 버전).

01STEP 1추천

방법 A · 웹 3D 게임 (스파이더맨 방식)

  • 조회 183만 영상의 게임은 Claude Code가 코드·셰이더·절차적 도시·Blender 모델·생성 텍스처를 전부 만들고, 사람은 피드백과 참고 이미지로 방향만 잡았어요(원작자 공개 저장소 설명). 브라우저에서 바로 돌아가요.
    1. 1컴퓨터에 Node.js(20 이상) 설치 → 게임용 빈 폴더 만들기 (예: my-game)
    2. 2그 폴더에서 Claude Code 실행
    3. 3아래 프롬프트의 괄호 부분을 내 게임으로 바꿔서 붙여넣기
    4. 4Claude가 다 만들면 "npm run dev" 실행 → 브라우저에서 안내된 주소(localhost) 열기
    5. 5해보고 고칠 점을 말하기 (아래 "고치는 문장" 참고)
  • 이렇게 쓰면 잘 나와요
    • 장르·조작키·분위기·목표를 한 문단에 다 쓰기
    • "단계마다 실행해서 스크린샷으로 확인해" 넣기
    • 참고 이미지(게임 스크린샷)를 같이 주기
  • 피할 것
    • "재밌는 게임 만들어줘"처럼 막연한 한 줄
    • 처음부터 기능 20개 요구하기 — 최소 버전 먼저
  • 웹 3D 게임 프롬프트 (한국어)
    브라우저에서 바로 돌아가는 3D 액션 게임을 처음부터 만들어줘.

[게임 한 문단]
주인공이 (도시 / 숲 / 우주 정거장) 위를 (거미줄로 날아다니며 / 제트팩으로 날며 / 파쿠르로 뛰어다니며) 목표 지점까지 가는 3인칭 게임이야. 조작은 WASD 이동, 스페이스 점프, 마우스 시점, 왼쪽 클릭 (스윙/대시). 분위기는 (맑은 오후의 대도시 / 비 오는 밤 네온).

[기술]
- Vite + Three.js(WebGL2)로 만들고, npm run dev로 바로 실행되게 해줘.
- 도시·지형은 절차적으로 생성해서 넓게. 건물 수천 개도 끊기지 않게 최적화(인스턴싱, LOD).
- 캐릭터·소품 모델은 Blender Python 스크립트로 만들어서 glTF로 내보내고, 텍스처·간판 이미지는 이미지 생성으로.
- 그림자, 블룸, 모션 블러, 낮/밤 프리셋을 넣어 실제 게임처럼 보이게.
- 화면에 미니맵, 조작 안내(H키) 넣기.

[진행 방식]
1) 먼저 계획(파일 구조, 단계)을 짧게 보여주고 바로 시작해.
2) 단계마다 실행해서 스크린샷으로 스스로 확인하고, 이상하면 고쳐.
3) 완성되면 내가 직접 해볼 수 있게 실행 방법을 알려줘.
  • TIP유명 게임 캐릭터를 그대로 쓰면 공개·판매할 수 없어요. 원작자도 비상업 팬 프로젝트로 공개했어요. 내 캐릭터로 바꿔서 만드세요.
02STEP 2방법 C

방법 C · 다크소울풍 액션 RPG (보스전)

  • 조회 60만 데모에는 타이틀 화면, 지역 이름 연출, 체력 바, 대검 보스와 2페이즈, "보스 처치" 문구까지 들어 있어요. 원작자가 출시 전 Opus 5.5를 미리 써보고 만든 데모예요. 아래 프롬프트는 이 데모의 구성을 그대로 체크리스트로 옮긴 거예요.
    1. 1방법 A와 같은 준비 (Node.js + 빈 폴더 + Claude Code)
    2. 2아래 프롬프트 붙여넣기 → "최소 버전"부터 플레이해 보기
    3. 3전투 감이 괜찮으면 "지역 2개 더", "보스 2페이즈"처럼 하나씩 추가
    4. 4분위기는 "따뜻한 햇빛, 먼지 파티클"처럼 눈에 보이는 말로
  • 액션 RPG 프롬프트 (한국어)
    다크소울 느낌의 3인칭 액션 RPG 데모를 만들어줘. 브라우저에서 돌아가게 Vite + Three.js로.

[게임 한 문단]
기사 한 명이 무너진 성(이름: 재의 관문)을 올라가며 지역 3곳을 지나고, 마지막에 대검을 든 보스와 싸우는 15분짜리 데모야.

[꼭 넣을 것]
- 타이틀 화면(새 게임 / 조작법 / 종료)
- 이동·구르기·약공격·강공격·방패 막기, 스태미나 바와 체력 바
- 지역에 들어가면 화면 가운데 지역 이름 표시 (예: 바깥 성곽)
- 회복 약병, 쉼터(모닥불)에서 부활
- 보스: 이름과 체력 바가 화면 아래에, 공격 패턴 3가지, 체력 절반에서 2페이즈
- 보스를 이기면 "보스 처치" 문구가 금색으로 크게
- 돌 질감, 따뜻한 햇빛, 먼지 파티클로 분위기

[진행 방식]
먼저 전투 하나(이동·공격·보스 1패턴)만 되는 최소 버전을 만들어서 내가 해보게 해줘. 그다음 지역·연출을 하나씩 늘려가.
  • TIP"최소 버전 먼저 → 하나씩 추가"가 핵심이에요. 한 번에 다 시키면 어디서 꼬였는지 찾기 어려워져요.
03STEP 3방법 B

방법 B · 로블록스 대전 게임 (스튜디오 연결)

  • 조회 46만 영상은 Claude가 한 번에 만든 로블록스 대전 게임이에요. 원작자는 로블록스 Toolbox(무료 에셋)만 썼다고 해요. 로블록스 스튜디오에는 MCP 서버가 들어 있어서, Claude Code가 스튜디오를 직접 열어 스크립트를 쓰고 플레이 테스트까지 해요.
    1. 1로블록스 스튜디오 최신 버전 설치 → 새 플레이스(Baseplate) 열기
    2. 2Claude Code 설치 후 스튜디오 재시작
    3. 3스튜디오에서 Assistant 설정(Assistant Settings) → MCP Servers → Quick connect 펼치기
    4. 4목록에서 Claude Code를 켜기 (안 보이면 Claude Code 설치 후 스튜디오 다시 켜기)
    5. 5스튜디오를 열어둔 채 Claude Code에 아래 프롬프트 붙여넣기
    6. 6완성되면 스튜디오에서 플레이 버튼으로 직접 해보기
  • 로블록스 대전 게임 프롬프트 (한국어)
    지금 열려 있는 로블록스 스튜디오에 2인 대전 격투 게임을 만들어줘.

[게임 한 문단]
밤의 네온 도시 거리에서 1대1로 싸우는 스매시브라더스 방식 게임이야. 맞을수록 % 피해가 쌓이고, 높을수록 멀리 날아가. 화면 밖으로 날아가면 목숨 1개 감소, 3개 다 잃으면 패배.

[꼭 넣을 것]
- 캐릭터 선택 화면 (내가 만든 오리지널 캐릭터 4명, 이름·기술 설명)
- 카운트다운 3-2-1 → GO!
- 기본 공격, 강공격, 필살기 1개씩. 필살기는 화면이 멈추고 기술 이름이 크게 뜨는 연출
- 화면 아래에 두 캐릭터 얼굴과 % 표시
- 승리 화면 (WINNER! + 결과표)
- 컴퓨터(CPU) 상대 모드

[진행 방식]
Toolbox의 무료 에셋을 써도 돼. 스크립트는 ServerScriptService·StarterPlayer에 나눠서 넣고, 다 만들면 플레이 모드로 직접 테스트해서 오류를 고쳐줘.
  • 주의MCP로 연결된 AI는 열려 있는 플레이스를 읽고 고칠 수 있어요. 중요한 게임은 복사본을 만들어 연결하세요. 애니메이션 캐릭터 등 남의 캐릭터를 쓰면 공개 시 문제가 될 수 있어요.
04STEP 4마무리

마무리 · 해보고 말로 고치기

  • "프롬프트 하나와 대략적인 아이디어로 만들었다"는 로블록스 게임도, 스파이더맨 게임도 결국 "해보고 → 말하고 → 다시 해보는" 반복으로 완성됐어요. 코드를 몰라도 느낌을 정확히 말하는 게 실력이에요.
    1. 110분 플레이 → 불편한 점 3개만 적기
    2. 2하나씩 말하기: 증상 + 원하는 느낌 (예: "점프가 낮아서 답답해, 지금의 1.5배로")
    3. 3고친 뒤 "다시 실행해서 스크린샷으로 확인해줘"
    4. 4마음에 들면 "지금 상태를 저장(커밋)해줘" — 망가져도 돌아갈 수 있어요
  • 고칠 점 전달 템플릿
    방금 해봤어. 고칠 점 3개야.
1) (증상) → (원하는 느낌)
2) (증상) → (원하는 느낌)
3) (증상) → (원하는 느낌)
하나씩 고치고, 고칠 때마다 실행해서 스크린샷으로 확인해줘. 다른 부분은 건드리지 마.

01웹 3D 게임 (영어)
Build a third-person 3D action game that runs in the browser, from scratch.

Game in one paragraph: the hero (web-swings / jetpacks / parkours) across a (city / forest / space station) to reach goals. Controls: WASD to move, Space to jump, mouse to look, left click to (swing / dash). Mood: (sunny afternoon metropolis / rainy neon night).

Tech: Vite + Three.js (WebGL2), runnable with npm run dev. Procedurally generate a large city/terrain and keep it smooth (instancing, LOD). Build character and prop models with Blender Python scripts exported as glTF; generate textures and billboard art with an image model. Add shadows, bloom, motion blur and day/night presets so it looks like a real game. Add a minimap and an in-game controls panel (H).

이럴 땐 이렇게

troubleshooting

자주 막히는 부분을 모았어요

Q코딩을 하나도 몰라도 돼요?
A

네. 원작자들도 코드를 직접 쓰지 않고 말로 지시했어요. 다만 "npm run dev" 같은 실행 명령은 Claude가 알려주는 대로 한 줄 입력해야 해요.

QClaude 앱이랑 Claude Code는 뭐가 달라요?
A

앱은 대화창 안에서 HTML 하나짜리 게임까지 돼요. Claude Code는 내 컴퓨터에서 파일 수백 개, Blender, 로블록스 스튜디오까지 다룰 수 있어서 영상 속 게임 수준은 Claude Code로 만들어요.

Q로블록스 Quick connect에 Claude Code가 안 보여요
A

Claude Code를 먼저 설치하고 로블록스 스튜디오를 완전히 껐다 켜세요. 그래도 없으면 공식 문서의 JSON 설정이나 명령어 방식으로 연결할 수 있어요.

Q게임이 하얀 화면만 나와요
A

Claude에게 "브라우저 콘솔 오류를 확인하고 고쳐줘"라고 하세요. 오류 메시지를 복사해서 붙여넣어도 돼요.

Q만든 게임을 팔아도 돼요?
A

내 캐릭터·내 에셋으로 만든 건 괜찮지만, 스파이더맨·애니메이션 캐릭터처럼 남의 캐릭터를 쓴 게임은 공개·판매하면 안 돼요.

용어 풀이

glossary

처음 보는 단어가 있다면

Claude Code
컴퓨터에서 Claude가 파일을 만들고 프로그램을 실행할 수 있게 해주는 도구.
Three.js
브라우저에서 3D 그래픽을 그리는 무료 라이브러리. 설치 없이 링크로 하는 3D 게임에 써요.
Blender
무료 3D 모델링 프로그램. Claude가 Python 스크립트로 캐릭터·소품 모델을 만들 수 있어요.
MCP
AI가 다른 프로그램(로블록스 스튜디오 등)을 직접 조작하게 해주는 연결 방식.
Toolbox
로블록스 스튜디오의 무료 에셋(모델·효과) 모음.
절차적 생성
도시·지형을 사람이 하나씩 배치하지 않고 규칙(코드)으로 자동 생성하는 방법.
npm run dev
웹 게임을 내 컴퓨터에서 실행하는 명령어. 실행 후 브라우저에서 localhost 주소를 열어요.
