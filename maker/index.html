  2. 2할 일“회의록으로 정리해줘” — 동사로 분명하게
  3. 3재료메모·사진·자료를 같이 붙여넣기
  4. 4조건길이·말투·꼭 넣을 것·하지 말 것
  5. 5모양표, 3줄, 메일처럼 받고 싶은 형태
