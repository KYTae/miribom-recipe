Blender 안 만지고 이 퀄 끝 — 말로만 시켜서 실사급 3D 장면 만들기 (Claude + Blender MCP)

Blender를 한 번도 직접 만지지 않고, Claude한테 말로만 시켜서 만든 3D 장면 두 편이 일본 X에서 터졌어요. @hayashimon1의 “비 오는 심야 코인 빨래방”(조회 64만, 저장 6.4천)과 @Yokohara_h의 어두운 사무실(조회 68만). 모델링·질감·조명·애니메이션까지 전부 AI가 했고, 사람이 한 일은 “여기가 이상해” 하고 판단해 준 것뿐이에요. 원작자가 답글로 공개한 제작 순서를 그대로 옮기고, 바로 복사해 쓰는 프롬프트로 정리했어요.

how it works

사람은 “목표 그림”과 “지적”만, 나머지는 Claude가 Blender 안에서

이렇게 작동해요

  1. 1목표 이미지ChatGPT 등으로 완성 장면 2D 한 장
  2. 2공간 → 모델 → 질감상자 배치부터 단계별로 정밀하게
  3. 3지적으로 다듬기“여기 이상해” → Claude가 클로즈업 확인 후 수정
  4. 4움직임 · 렌더비·조명·카메라 지시 → mp4

Blender MCP(커넥터)를 연결하면 Claude가 열려 있는 Blender를 직접 조작해요. 핵심은 한 번에 다 만들라고 하지 않는 거예요. 완성 이미지를 먼저 보여주고, 상자로 공간을 잡고, 모델을 다듬고, 마지막에 질감과 사용감을 입히는 순서로 나눠서 시켜요. 사람은 렌더 결과를 보고 “부자연스러워”, “여백이 많아”처럼 판단만 해주면 돼요.

준비물

  • ClaudeOpus 5.5를 쓸 수 있는 요금제. 원작은 Claude Code로 만들었어요(Claude 데스크톱 앱도 가능).
  • Blender + Blender MCPblender.org에서 무료 설치. Blender 공식 커넥터는 Blender 5.1 이상(설치 순서는 28편 방법 B 참고).
  • 이미지 생성 도구완성 목표 이미지 한 장용. ChatGPT·Gemini 등 아무거나 괜찮아요.
  • 컴퓨터원작자는 MacBook Air로 만들었어요. 렌더가 거칠면 AI 문제가 아니라 샘플 수 문제 — 시간을 더 들이면 깨끗해져요.

01STEP 1원본 A

원본 A · 비 오는 심야 코인 빨래방 (7단계)

  • @hayashimon1은 “Claude Opus 5.5에게 지시만 해서 Blender로 분위기 있는 코인 빨래방 3DCG를 만들었다, Blender는 손으로 전혀 조작하지 않았다”며 10초 영상을 올렸어요. 폭우 내리는 밤, 1대만 돌아가는 건조기, 깜빡이는 형광등. 모델링도 질감도 애니메이션도 거의 일본어 지시만으로 했고, 답글로 제작 순서를 공개했어요. 사용 도구는 Claude Code × Blender MCP, 컴퓨터는 MacBook Air예요.
    1. 1완성 목표 이미지 만들기 — ChatGPT로 최종 모습 2D 이미지 한 장 생성 (아래 프롬프트)
    2. 2이미지를 Claude에 주고 “이 이미지로 심야 코인 빨래방을 Blender로 만들어줘” — 유리 입구·벤치·세탁기 배열까지 레이아웃을 읽어서 공간을 짜요
    3. 3공간 → 모델 → 질감 순서로 정밀하게 — 처음엔 상자만 놓는 블록아웃, 그다음 세탁기 드럼에 불리언으로 구멍, 빨래는 천 시뮬레이션
    4. 4사용감 질감 — 모서리 페인트 벗겨짐·틈새 때·먼지·바닥 얼룩·흘러내린 자국·지문을 노드 그룹 하나로 모든 재질에 강도만 바꿔 겹침 (이미지 텍스처 없이 전부 절차적)
    5. 5간판·스티커는 “인쇄물”로 — 3D 글자는 CG 티가 나서, Blender 안에서 2D로 디자인 → 위에서 렌더 → 텍스처로, 색 바램·누렇게·코팅 광택·벗겨짐 추가
    6. 6지적으로 다듬기 — “부자연스러운 곳이 많아”, “간판 여백이 많아”, “바닥을 참고 이미지처럼” → Claude가 클로즈업으로 하나씩 확인하며 수정
    7. 7움직임 지시 후 렌더 — 건조기 회전과 빨래, 불규칙한 형광등, 돌풍에 흔들리는 창, 비스듬한 비, 천천히 전진하는 카메라 → mp4
  • 1단계 · 목표 이미지 (ChatGPT 등에 붙여넣기)
    비 오는 심야의 작은 코인 빨래방 내부를 사진처럼 그려줘.
- 왼쪽: 유리문과 큰 창, 밖에는 비스듬히 내리는 비와 젖은 도로의 불빛 반사
- 오른쪽 벽: 드럼 세탁기·건조기가 2단으로 줄지어 있고, 그중 건조기 1대만 돌아가는 중
- 창가에 금속 벤치, 가운데 접는 테이블과 빨래 바구니, 바닥에 파란 양동이
- 천장에 형광등 2개(하나는 살짝 깜빡이는 느낌), 벽에 이용 안내 포스터와 스티커
- 오래 쓴 공간: 바닥 얼룩, 모서리 벗겨진 페인트, 먼지
- 16:9, 사람 키 높이에서 안쪽을 바라보는 구도, 차갑고 조용한 분위기
  • 2~5단계 · Blender 제작 지시 (Claude에 이미지와 함께)
    첨부한 이미지를 완성 목표로 해서, 심야의 코인 빨래방을 Blender로 만들어줘.

순서는 꼭 이렇게:
1) 공간: 먼저 상자만으로 방·창·문·기계 위치를 잡는 블록아웃. 이미지와 같은 카메라 각도를 맞추고 한 장 렌더해서 보여줘.
2) 모델: 세탁기 드럼은 불리언으로 구멍을 내서 깊이를 만들고, 빨래는 천 시뮬레이션으로 떨어뜨려 모양을 잡아줘.
3) 질감: 모든 재질에 '사용감' 노드 그룹 하나를 강도만 바꿔서 겹쳐줘 — 모서리 페인트 벗겨짐, 틈새 때, 윗면 먼지, 바닥 가장자리 얼룩, 흘러내린 자국, 지문. 이미지 텍스처 없이 전부 절차적으로.
4) 간판·스티커: 3D 글자 대신 Blender 안에서 2D로 디자인 → 위에서 렌더 → 텍스처로 붙이고, 색 바램·누렇게 변함·코팅 광택·벗겨짐을 겹쳐줘.

단계마다 렌더 이미지를 보여주고, 내가 확인하면 다음 단계로 넘어가.
  • TIP원작자 한마디: “사람의 일은 좋고 나쁨을 판단하고 지시하는 것.” 렌더가 지글거리는 건 샘플 수가 낮아서예요. AI가 렌더 속도까지 바꿔주진 못하니, 마지막엔 시간을 들여 렌더하면 해결돼요.
02STEP 2원본 B

원본 B · 어두운 사무실 (AI가 만드는 법까지 판단)

  • @Yokohara_h는 “Blender를 내 손으로 한 번도 만지지 않고, 모델링까지 AI만으로”라는 제약을 걸고 26초 장면을 만들었어요. GPT-6 Astra와 Opus를 함께 썼고, 오브젝트마다 Blender에서 직접 모델링할지, 이미지 생성 → 3D 생성 → Blender 수정으로 갈지를 AI가 판단하게 했대요. 피드백은 꼼꼼히 줬지만, 조명·컴포지트·카메라워크는 거의 지적 없이 좋은 수준까지 나왔고, 볼류메트릭 포그는 “AI가 나보다 빠르고 잘하는 것 같다”고 해요.
    1. 1장면을 글로 설명하고 아래 프롬프트로 “오브젝트별 제작 방법 표”부터 받기
    2. 2표를 보고 이상한 곳만 바꿔 달라고 하기
    3. 3모델이 다 나오면 조명·포그·컴포지트는 맡겨 보기
    4. 4카메라 움직임은 “천천히 앞으로”, “책상 위를 스치듯”처럼 짧게
  • 오브젝트별로 만드는 법을 AI가 고르게
    이 장면을 Blender로 만들어줘. 오브젝트마다 두 방법 중 더 나은 쪽을 네가 판단해서 골라:
(1) Blender에서 직접 모델링 (2) 이미지 생성 → 3D 생성 → Blender에서 수정.
어떤 오브젝트를 어느 방법으로 할지 먼저 표로 보여주고 시작해. 마지막에 볼류메트릭 포그와 컴포지트로 분위기를 잡아줘.
  • TIP사람이 많이 손댄 부분은 모델링 피드백이었고, 분위기(조명·안개·색)는 AI가 오히려 빨랐다는 게 원작자 후기예요. 분위기 단어는 짧게 주고 결과를 먼저 보세요.
03STEP 3움직임

움직임 · 10초 영상으로 뽑기

  • 장면이 완성되면 “움직이는 것”을 하나씩 지시해요. 원작에서 효과가 컸던 건 작은 디테일이에요. 1대만 도는 건조기, 하나만 불규칙하게 깜빡이는 형광등, 돌풍에 흔들리는 창, 비스듬한 비. 카메라는 아주 천천히 앞으로만 가도 영화처럼 보여요.
  • 움직임 + 렌더 지시
    이제 움직임을 넣고 10초 영상으로 렌더해줘.
- 건조기 1대만 돌아가고, 안에서 빨래가 날리듯 굴러감
- 형광등 하나가 불규칙하게 깜빡임
- 돌풍이 불 때 창문이 살짝 흔들림
- 창밖에 비스듬히 내리는 비
- 카메라는 아주 천천히 앞으로 전진
1920x1080, 24fps로 렌더해서 mp4로 줘.
  • 지적해서 다듬기 (원작자 실제 지적 기반)
    전체적으로 부자연스러운 곳이 많아. 각 부분을 클로즈업으로 렌더해서 하나씩 확인하고 고쳐줘.
- 간판·포스터의 여백이 너무 많아
- 바닥을 참고 이미지처럼 더 오래되고 얼룩지게
- 고친 곳은 전후 비교 이미지로 보여줘
  • 이런 디테일이 실사 느낌을 만들어요
    • 전부 움직이지 말고 “하나만” 움직이기 (건조기 1대, 형광등 1개)
    • 불규칙함: 일정하지 않은 깜빡임·바람
    • 날씨: 비·김·먼지 같은 공기 속 입자
    • 카메라: 느린 전진 하나면 충분
04STEP 4응용

응용 · 한국 버전 장면으로 바꾸기

  • 같은 순서로 장면만 바꾸면 돼요. 잘 나오는 장면은 “작은 실내 + 밤 + 조명 하나 + 날씨”예요. 사람이 없는 공간이 AI 3D에서 가장 그럴듯하게 나와요. 목표 이미지 프롬프트의 장소와 소품만 바꾸고, 제작 지시는 그대로 쓰세요.
  • 이런 장면이 잘 나와요
    • 비 오는 밤 골목 편의점 — 계산대·냉장고 불빛·젖은 유리
    • 새벽 분식집 — 김 나는 떡볶이 판, 형광등, 메뉴판 스티커
    • 눈 오는 밤 버스 정류장 — 노선도 포스터, 깜빡이는 가로등
    • 시험 기간 독서실 — 스탠드 불빛, 쌓인 문제집, 창밖 새벽
    • 옥탑방 — 빨랫줄, 평상, 멀리 보이는 도시 불빛
  • 처음엔 피하세요
    • 사람·동물 등장 — 얼굴·털은 아직 어려워요
    • 넓은 야외·도시 전체 — 오브젝트가 너무 많아져요
    • 한 번에 “완성해줘” — 단계를 나눠야 품질이 나와요

12Blender 제작 지시 (영어)
Use the attached image as the target and build a late-night coin laundry in Blender.

Work in this order:
1) Space: block out the room, windows, door and machines with simple boxes first. Match the camera angle of the image and show me one render.
2) Models: cut the washer drums with booleans for real depth, and drop the laundry with a cloth simulation.
3) Materials: make one "wear" node group and layer it on every material at different strengths — chipped paint on edges, grime in gaps, dust on top surfaces, dirt along the floor edge, drip stains, fingerprints. No image textures, everything procedural.
4) Signs and stickers: instead of 3D text, design them in 2D inside Blender, render from straight above and use that as a texture, then add fading, yellowing, laminate gloss and peeling.

Show me a render after each step and wait for my OK before moving on.

easy way

이미지 한 장 + 지시 두 번

  • ChatGPT로 원하는 방 사진 같은 이미지 1장
  • Claude(Blender 연결)에 이미지와 함께 한 줄
  • 렌더 보고 “여기 이상해” 지적
  • “10초 영상으로 렌더해줘”
한국어 한 줄
첨부 이미지를 목표로 이 공간을 Blender로 만들어줘. 상자 배치 → 모델 → 사용감 질감 순서로 단계마다 렌더해서 보여주고, 마지막에 카메라가 천천히 앞으로 가는 10초 영상으로 렌더해줘.

이럴 땐 이렇게

troubleshooting

자주 막히는 부분을 모았어요

Q정말 Blender를 하나도 몰라도 돼요?
A

두 원작자 모두 Blender를 손으로 조작하지 않았어요. 다만 Blender 설치와 커넥터(MCP) 연결은 한 번 해야 해요. 그다음부터는 말로 지시하고 결과를 판단만 하면 돼요.

Q28편·30편이랑 뭐가 달라요?
A

28·30편은 점토 애니(클레이메이션)였어요. 이번 편은 실사처럼 보이는 공간 장면이고, “목표 이미지 → 단계별 지시 → 지적” 순서가 핵심이에요.

Q시간은 얼마나 걸려요?
A

원작자들이 정확한 시간을 밝히진 않았지만, 단계마다 렌더를 보고 지적하는 왕복이 여러 번 필요해요. 처음엔 하루 저녁 정도 잡으세요. 최종 렌더는 컴퓨터에 따라 달라요.

Q렌더가 지글지글해요
A

샘플 수가 낮아서예요(원작자 답변). 확인할 때는 낮게, 최종 렌더만 샘플을 올리고 디노이즈를 켜세요.

QGPT-6 Astra도 써야 해요?
A

@Yokohara_h는 Astra와 Opus를 같이 썼지만, @hayashimon1은 Opus만으로 만들었어요. 모델링 이해도는 Opus가 더 높게 느껴졌다고 해요.

꿀팁

tips
  1. 1

    한 번에 “완성해줘”가 아니라, 공간 → 모델 → 질감 → 움직임으로 나눠 단계마다 확인하세요.

  2. 2

    깨끗할수록 CG 같아요. 먼지·때·지문 같은 “사용감”이 실사 느낌의 핵심이에요.

  3. 3

    글자는 3D로 세우지 말고 인쇄물 텍스처로. 이것 하나로 확 진짜 같아져요.

  4. 4

    움직이는 건 하나만. 건조기 1대, 형광등 1개가 전부 움직이는 것보다 진짜 같아요.

glossary

처음 보는 단어가 있다면

Blender MCP
Claude 같은 AI가 Blender를 직접 조작하게 해주는 연결 방식. Claude에서는 “커넥터”로 추가해요.
블록아웃
상자 같은 단순한 모양으로 공간 배치만 먼저 잡는 단계.
불리언
도형끼리 빼거나 합쳐서 구멍을 내는 3D 기능. 세탁기 드럼 구멍을 이렇게 만들어요.
천 시뮬레이션
천이 떨어지고 접히는 걸 물리 계산으로 만드는 기능. 빨래 모양을 자연스럽게.
절차적 질감
사진 텍스처 없이 규칙(노드)으로 만드는 표면. 강도 숫자만 바꿔서 조절해요.
노드 그룹
여러 재질 설정을 하나로 묶은 부품. 한 번 만들어 모든 재질에 재사용해요.
볼류메트릭 포그
공기 중 안개·먼지를 표현해 빛줄기가 보이게 하는 효과.
샘플 수
렌더할 때 빛을 계산하는 횟수. 낮으면 지글거리고, 높으면 깨끗하지만 오래 걸려요.
