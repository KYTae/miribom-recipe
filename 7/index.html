AI한테 3만5천 원 줬더니 렌즈 실험실이 생겼어요

"카메라 초점 원리 설명해줘"라고 했더니 설명 글이 아니라 직접 만지는 3D 렌즈 실험실이 나왔어요. 요청 한 번, 1시간 26분, 약 3만5천 원. 모르는 원리를 체험판으로 배우는 방법을 무료 버전부터 정리했어요.

크게 만드는 법

따라 하는 법

method
01STEP 1

웹 챗봇에 "체험판"으로 요청하기

  • Claude.ai나 ChatGPT에 아래처럼 "설명해줘" 대신 "직접 조작할 수 있는 체험판을 만들어줘"라고 요청해요.
  • 렌즈 초점 체험판
    카메라 렌즈 초점이 맞는 원리를 직접 조작하며 배우는 인터랙티브 체험판을 HTML 파일 하나로 만들어줘. 빛이 렌즈를 지나 초점이 맺히는 경로를 그림으로 보여주고, 초점 링 슬라이더를 움직이면 선명한 위치가 바뀌게. 한국어 설명을 짧게 곁들여줘.
  • TIPClaude는 오른쪽 아티팩트 창, ChatGPT는 캔버스에서 바로 실행해볼 수 있어요.
02STEP 2

하나씩 고쳐서 키우기

    1. 1"조리개 슬라이더도 추가해줘"
    2. 2"배경 흐림(심도)이 바뀌는 사진 예시를 넣어줘"
    3. 3"중학생 눈높이로 퀴즈 3문제 추가"
  • TIP한 번에 많이 요청하면 망가지기 쉬워요. 하나 추가 → 확인 → 다음 순서가 좋아요.
03STEP 3선택

크게 만들기: 코딩 AI에 맡기기

  • Claude Code 같은 코딩 AI는 파일을 만들고 스스로 실행해 확인하면서 오래 작업할 수 있어요.
  • 원작 같은 실험실
    Build an interactive 3D "lens lab" web app that teaches how camera focus works. Model a real multi-element lens, trace light rays through each glass element, and let users rotate the focus ring and aperture to see the focal plane and depth of field change. Add short Korean explanations. Test it yourself and fix any bugs before finishing.
  • 주의API로 오래 작업시키면 비용이 계속 나가요. 원작은 약 25.66달러가 들었어요.

주제만 바꿔 쓰기

HTML 파일 하나로 만들어 달라고 하면 바로 실행돼요

01블랙홀 중력렌즈
블랙홀 주변에서 빛이 휘는 원리를 체험하는 인터랙티브 웹페이지를 HTML 하나로 만들어줘. 마우스로 블랙홀을 움직이면 뒤쪽 별빛이 휘어 보이게. 한국어 설명 포함.
02자동차 엔진 4행정
4행정 엔진(흡입-압축-폭발-배기) 원리를 애니메이션으로 보여주는 체험판을 HTML 하나로 만들어줘. 속도 슬라이더와 단계별 일시정지 버튼, 한국어 설명 포함.
03복리 계산 체험
복리와 단리의 차이를 체험하는 웹페이지를 HTML 하나로 만들어줘. 원금·이율·기간 슬라이더를 움직이면 두 그래프가 실시간으로 바뀌고, 30년 뒤 차이를 크게 보여줘.

돈 공부

04심장 혈액 순환
심장에서 피가 도는 경로를 애니메이션으로 보여주는 체험판을 HTML 하나로 만들어줘. 심방·심실을 누르면 이름과 역할이 나오고, 심박수 슬라이더로 속도 조절.

이럴 땐 이렇게

troubleshooting

자주 막히는 부분을 모았어요

Q결과가 실행이 안 돼요
A

"HTML 파일 하나로, 외부 파일 없이"를 꼭 넣으세요. 에러가 나면 화면 캡처나 에러 문구를 붙여넣고 고쳐 달라고 하세요.

Q무료 버전도 원작만큼 나와요?
A

규모는 작아요. 원작은 코딩 AI가 1시간 넘게 스스로 확인하며 만든 결과예요. 무료 버전은 핵심 원리 하나에 집중하면 충분히 쓸 만해요.
