"헤이 잭" 한마디에 벽 전광판이 AI 비서로

OpenAI 직원이 사이드 프로젝트로 만든 음성 AI 전광판 "잭"이에요. 말로 부탁하면 날씨, 예보 그래프, 사진까지 벽에 띄워줘요. 만든 사람도 LED와 라즈베리파이는 처음이었대요. 하드웨어 없이 해보는 방법부터 정리했어요.

라즈베리파이에 마이크·스피커·LED 패널을 연결하고, 대화는 실시간 음성 AI가, 검색·일정 확인은 다른 모델이 맡아요. 막히는 부분은 코딩 AI(Codex)에게 물어보며 만들었대요.

  • 코딩 AICodex·Claude Code 등 (유료)
  • API 키음성 AI를 쓰려면 OpenAI API 결제 필요

method
01STEP 1

화면 버전: 전광판 디자인 만들기

  • 웹 챗봇에 넣기
    128×64 픽셀 LED 전광판처럼 보이는 웹페이지를 HTML 파일 하나로 만들어줘. 도트가 보이는 픽셀 글꼴로 현재 시각, 날짜, 날씨 아이콘과 기온을 보여주고, 버튼을 누르면 "일주일 예보 그래프" 화면과 "도시 야경 픽셀 아트" 화면으로 바뀌게.
  • TIP실제 날씨 대신 예시 데이터로 먼저 만들고, 마음에 들면 다음 단계에서 진짜 데이터를 연결해요.
02STEP 2

화면 버전: 말로 바꾸기

  • 음성 명령 추가
    위 전광판에 마이크 버튼을 추가해줘. 브라우저 음성 인식으로 "날씨", "예보", "야경" 같은 말을 알아들으면 해당 화면으로 바뀌게. 한국어로 말해도 되게 해줘.
  • TIP크롬 브라우저에서 마이크 권한을 허용해야 작동해요.
03STEP 3선택

하드웨어 버전: 코딩 AI와 함께 조립

  • 원작자처럼 처음이어도 괜찮아요. 부품을 산 뒤 코딩 AI에게 단계별로 물어보며 진행해요.
  • 코딩 AI에 첫 질문
    라즈베리파이에 128×64 RGB LED 패널(HUB75)을 연결해서 글자를 띄우고 싶어. 나는 처음이야. 필요한 부품 목록, 배선 순서, 설치할 라이브러리, 첫 테스트 코드까지 단계별로 알려줘. 각 단계가 성공했는지 확인하는 방법도.
  • 음성 비서 연결
    이제 USB 마이크로 "헤이 잭"을 들으면 OpenAI 실시간 음성 API로 대화하고, 날씨를 물으면 LED에 날씨 화면을 띄우게 만들어줘. API 키는 환경 변수로 넣을게. 말하는 도중 끼어들어도 멈추고 듣게 해줘.
  • 주의전원 어댑터는 LED 패널 사양에 맞는 걸 써야 해요. 실시간 음성 API는 사용한 만큼 비용이 나가요.

A
