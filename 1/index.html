method
01STEP 1

화면 버전: 전광판 디자인 만들기

  • 웹 챗봇에 넣기
    128×64 픽셀 LED 전광판처럼 보이는 웹페이지를 HTML 파일 하나로 만들어줘. 도트가 보이는 픽셀 글꼴로 현재 시각, 날짜, 날씨 아이콘과 기온을 보여주고, 버튼을 누르면 "일주일 예보 그래프" 화면과 "도시 야경 픽셀 아트" 화면으로 바뀌게.
  • TIP실제 날씨 대신 예시 데이터로 먼저 만들고, 마음에 들면 다음 단계에서 진짜 데이터를 연결해요.
    1. 1챗봇 답에서 코드 전체를 복사해요
    2. 2메모장에 붙여넣고 이름을 jack.html로 저장해요
    3. 3저장한 파일을 더블클릭해 크롬에서 열어요
    4. 4마음에 안 드는 부분은 같은 대화에 이어서 고쳐 달라고 해요
02STEP 2

화면 버전: 말로 바꾸기

  • 음성 명령 추가
    위 전광판에 마이크 버튼을 추가해줘. 브라우저 음성 인식으로 "날씨", "예보", "야경" 같은 말을 알아들으면 해당 화면으로 바뀌게. 한국어로 말해도 되게 해줘.
  • TIP크롬 브라우저에서 마이크 권한을 허용해야 작동해요.
  • 이런 명령이 잘 알아들어요
    • 날씨, 예보처럼 짧은 단어 하나
    • 조용한 곳에서 또박또박
    • 명령 단어를 미리 정해서 프롬프트에 적어두기
03STEP 3선택

하드웨어 버전: 코딩 AI와 함께 조립

  • 원작자처럼 처음이어도 괜찮아요. 부품을 산 뒤 코딩 AI에게 단계별로 물어보며 진행해요.
  • 코딩 AI에 첫 질문
    라즈베리파이에 128×64 RGB LED 패널(HUB75)을 연결해서 글자를 띄우고 싶어. 나는 처음이야. 필요한 부품 목록, 배선 순서, 설치할 라이브러리, 첫 테스트 코드까지 단계별로 알려줘. 각 단계가 성공했는지 확인하는 방법도.
  • 음성 비서 연결
    이제 USB 마이크로 "헤이 잭"을 들으면 OpenAI 실시간 음성 API로 대화하고, 날씨를 물으면 LED에 날씨 화면을 띄우게 만들어줘. API 키는 환경 변수로 넣을게. 말하는 도중 끼어들어도 멈추고 듣게 해줘.
  • 주의전원 어댑터는 LED 패널 사양에 맞는 걸 써야 해요. 실시간 음성 API는 사용한 만큼 비용이 나가요.
  • TIP부품은 사기 전에 모델명을 코딩 AI에 먼저 보내서 서로 맞는지 확인받으세요.

01내 전광판 기획 — 먼저 질문받기
나만의 AI 전광판을 만들고 싶어. 아직 무엇을 띄울지 정하지 못했어.
- 놓을 곳: [예: 거실 벽 / 책상 위 / 가게 입구]
- 주로 볼 사람: [예: 나 혼자 / 가족 / 손님]
코드를 쓰기 전에 나한테 질문 5개를 먼저 해줘(보여줄 정보, 바꾸는 방법, 분위기 등).
내 답을 받으면 화면 3~4개 구성안을 표로 정리해줘 (화면 이름 · 보여줄 내용 · 바뀌는 조건).

무엇을 띄울지 막막할 때 — 웹 챗봇에 먼저 보내요

02화면 버전 — 내 정보로 전광판 만들기
128×64 픽셀 LED 전광판처럼 보이는 웹페이지를 HTML 파일 하나로 만들어줘.
- 화면 구성: [보여줄 정보 3개, 예: 시계 · 오늘 날씨 · 할 일 3개]
- 분위기: [예: 검은 배경에 주황 도트, 레트로 오락실 느낌]
- 화면 전환: 버튼을 누르거나 [예: 10초마다] 자동으로 다음 화면으로
- 데이터는 일단 예시 값으로 채우고, 나중에 진짜 데이터로 바꾸기 쉽게 한곳에 모아줘
도트가 보이는 픽셀 글꼴을 쓰고, 파일 하나만 열면 바로 보이게 해줘.

원작 프롬프트를 내 화면 구성에 맞게 바꿔 쓴 버전

03화면 버전 — 내 말로 부르는 음성 명령
방금 만든 전광판에 마이크 버튼을 추가해줘. 크롬 브라우저 음성 인식을 써서 한국어로 알아듣게 해줘.
- 부르는 이름: [예: 잭 / 미리 / 우리 집 이름]
- 명령과 화면 연결: [예: 날씨 → 날씨 화면, 할 일 → 할 일 화면, 사진 → 사진 화면]
- 못 알아들으면 화면 아래에 "다시 말해주세요"를 2초 띄워줘
- 지금 듣는 중인지 알 수 있게 마이크 표시가 깜빡이게 해줘
마지막에 내가 말해볼 테스트 문장 5개를 알려줘.

전광판 코드를 만든 그 대화에 이어서 보내요

04화면 버전 — 진짜 날씨 연결하기
전광판의 예시 날씨를 진짜 날씨로 바꾸고 싶어. 위치는 [도시, 예: 서울 강남구]야.
- 회원가입이나 API 키 없이 쓸 수 있는 방법이 있으면 그걸로, 없으면 키가 필요한 이유와 받는 순서를 알려줘
- [예: 30분]마다 자동으로 새로 불러오게
- 인터넷이 끊기면 마지막 값을 그대로 두고 작게 '업데이트 실패'라고 표시
바뀐 부분이 어디인지 먼저 설명한 다음, 전체 코드를 다시 줘.

디자인이 마음에 든 다음에 — 같은 대화에 이어서

05막혔을 때 — 오류 그대로 붙여넣기
전광판을 만들다가 막혔어. 나는 코딩이 처음이야.
- 지금 하던 단계: [예: 크롬에서 html 파일 열기 / 라즈베리파이에 라이브러리 설치]
- 기대한 결과: [예: 시계가 보여야 함]
- 실제 증상: [예: 화면이 하얗게만 나와요]
- 오류 메시지: [오류 문장을 그대로 복사]
원인일 가능성이 높은 것부터 3개를 쉬운 말로 알려주고, 내가 하나씩 확인할 수 있게 순서대로 안내해줘. 한 번에 하나만 시켜줘.

화면 버전·하드웨어 버전 모두 — 오류 문장은 고치지 말고 그대로

06하드웨어 — 내 부품으로 조립 계획
라즈베리파이로 LED 전광판을 만들려고 해. 나는 처음이야. 아래 부품이 서로 맞는지 먼저 확인해줘.
- 라즈베리파이 모델: [예: 모델명 그대로]
- LED 패널: [예: 128×64 RGB, HUB75, 판매 페이지 제품명]
- 연결 보드·전원: [예: 패널 연결 보드 이름, 전원 어댑터 V·A]
맞지 않거나 빠진 부품이 있으면 먼저 알려줘. 그다음 배선 → 라이브러리 설치 → 글자 띄우기 테스트를 단계별로, 단계마다 성공했는지 확인하는 방법과 함께 알려줘.

원작 첫 질문을 내 부품 모델명으로 바꿔 쓴 버전 · 코딩 AI에

07하드웨어 — 음성 비서 성격·안전장치
LED 전광판 음성 비서의 성격과 규칙을 정해서 코드에 넣어줘.
- 이름과 말투: [예: 잭, 짧고 친근한 반말]
- 할 수 있는 일: [예: 날씨, 시계, 오늘 일정 읽어주기]
- 대답은 2문장 이내, 화면에는 핵심 단어만
- 비용 안전장치: 아무도 말하지 않으면 [예: 30초] 뒤 대화를 끊고, 하루 사용 횟수를 기록해서 로그로 남겨줘
API 키는 코드에 직접 적지 말고 환경 변수에서 읽게 해줘.

이럴 땐 이렇게

troubleshooting

자주 막히는 부분을 모았어요

Q코딩을 몰라도 되나요?
A

화면 버전은 프롬프트만 복사하면 돼요. 하드웨어 버전은 코딩 AI가 알려주는 명령어를 따라 할 수 있으면 충분해요.

QAPI 키가 뭐예요?
A

프로그램이 AI를 쓸 수 있게 해주는 비밀번호 같은 거예요. 남에게 보여주거나 코드에 그대로 적어 올리면 안 돼요.

Q하드웨어는 얼마나 들어요?
A

LED 패널·라즈베리파이·전원 장치를 합쳐 보통 십몇만 원대부터 시작해요. 먼저 화면 버전으로 디자인을 정한 뒤 사는 게 좋아요.

QAPI 요금이 걱정돼요
A

실시간 음성 API는 쓴 만큼 요금이 나와요. 개발자 콘솔에서 월 한도를 먼저 걸어두세요.

Q받은 코드를 어디에 붙여요?
A

메모장(맥은 텍스트 편집기)에 붙여넣고 이름 끝을 .html로 저장한 뒤 더블클릭하면 브라우저에서 열려요. 챗봇 화면에서 바로 미리보기가 되면 그걸로 먼저 확인해도 돼요.

Q폰으로도 돼요?
A

프롬프트 보내기는 폰 앱으로도 돼요. 다만 html 파일 저장·열기와 마이크 테스트는 컴퓨터 크롬이 훨씬 편해요.

Q마이크 버튼을 눌러도 반응이 없어요
A

주소창 옆 권한 표시에서 마이크를 허용했는지 보세요. 그래도 안 되면 증상을 그대로 챗봇에 보내 원인을 물어보세요.

Q화면이 하얗게만 나와요
A

코드가 중간에 잘렸을 때가 많아요. "전체 코드를 다시 줘"라고 보내서 처음부터 끝까지 다시 복사하세요.

Q무료로 어디까지 돼요?
A

화면 버전은 무료 챗봇과 브라우저만으로 돼요. 실시간 음성 API와 코딩 AI는 유료예요.
