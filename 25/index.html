모션팀이 3주 걸릴 영상, Opus 5.5는 15분

Claude Opus 5.5는 영상을 "그리는" 대신 영상을 만드는 코드를 써요. 그래서 한 문장으로도 모션그래픽 쇼릴이 나오고, 1,500만 명이 본 서양 문명사 영상도 이렇게 만들어졌어요. 그런데 한 줄만 쓰면 다들 비슷한 결과가 나와요. 원작자들이 공개한 프롬프트와, 결과를 확 바꾸는 4단계 워크플로를 정리했어요.

어떻게 만들어요?

how it works

Claude는 영상을 직접 그리지 않고, 영상을 만드는 코드를 써요

이렇게 작동해요

  1. 1지시한 문장 or 레퍼런스
  2. 2코드 작성HTML·React 장면
  3. 3렌더Remotion 등 → mp4
  4. 4수정한 줄 고치고 다시 렌더

장면마다 코드로 만들기 때문에 글자가 깨지지 않고, "이 부분만 바꿔줘" 하면 그 장면 코드만 고쳐서 다시 렌더해요. 영상 생성 AI처럼 매번 처음부터 뽑지 않아도 돼요.

준비물

  • ClaudeOpus 5.5를 쓸 수 있는 요금제 (Claude 앱 또는 Claude Code — 영상은 Claude Code 추천)
  • 렌더 도구Remotion 또는 HyperFrames — Claude가 코드로 만든 장면을 mp4로 바로 뽑아줘요
  • 레퍼런스 영상따라 하고 싶은 스타일의 영상 1~2개 (whatships.com 같은 런칭 영상 모음에서)
  • 시간쇼릴 15분 정도, 다듬는 시간 포함 1시간이면 충분해요

따라 하는 법

method
01STEP 1

한 문장으로 쇼릴 뽑기 (가장 쉬워요)

  • 원작자가 "한 문장"으로 15분 만에 만든 쇼릴이에요. 모션팀에 맡기면 3~4주, 8,000~10,000달러가 든다고 해요.
  • 쇼릴 프롬프트 (원문)
    make a dynamic 15-second motion graphics video that shows what an incredible motion designer you are, like it's your showreel for a résumé. go all out.
  • 한국어 버전
    네가 얼마나 뛰어난 모션 디자이너인지 보여주는 15초짜리 역동적인 모션그래픽 영상을 만들어줘. 이력서에 넣을 쇼릴처럼. 전력을 다해서.
  • TIP"go all out(전력을 다해)" 같은 한마디가 결과를 꽤 바꿔요. 주제만 바꿔서 "우리 카페 소개 15초 영상"처럼 써도 돼요.
02STEP 2

① 레퍼런스 영상 고르고 ② 렌더 도구 연결

  • 레퍼런스 없이 시키면 Opus는 늘 같은 기본 스타일(가운데 글자, 그라데이션 배경, 페이드 인)로 돌아가요. 그래서 다들 비슷해 보여요.
    1. 1whatships.com 같은 런칭 영상 모음에서 마음에 드는 영상 1~2개 고르기
    2. 2스타일을 말로 설명하지 말고 "이 영상처럼"이라고 레퍼런스를 주기
    3. 3Remotion(또는 HyperFrames) 설치 → Claude가 장면을 코드로 쓰고 mp4로 바로 렌더
    4. 4수정할 땐 "3번 장면 글자만 키워줘"처럼 장면 단위로
  • 레퍼런스 지시
    첨부한 레퍼런스 영상의 속도감, 글자 배치, 전환 방식을 그대로 따라서 (주제) 영상을 만들어줘. Remotion으로 장면마다 코드로 만들고 mp4로 렌더해줘. 길이 20초, 16:9.
03STEP 3

③ 진짜 UI 부품 쓰고 ④ 스토리보드 3개 먼저

  • 제품 화면이 나오는 영상이면 버튼·카드를 Opus가 즉석에서 그리게 두지 마세요. 간격이 어색하고 가짜처럼 보여요.
  • UI 컴포넌트 지시
    영상에 나오는 버튼, 카드, 대시보드 같은 UI는 직접 그리지 말고 21st.dev 컴포넌트를 써줘. 우리 브랜드 색 (색상 코드)과 폰트 (폰트 이름)에 맞춰줘.
  • 스토리보드 먼저
    바로 영상을 만들지 말고, 스토리보드를 3가지 버전으로 먼저 보여줘. 장면마다 정지 화면 1장씩. 내가 고른 버전으로만 영상을 만들어줘.
  • TIP스토리보드 단계에서 고치는 게 렌더된 영상을 고치는 것보다 훨씬 싸고 빨라요.

easy way

Claude 앱(웹)만으로 5분 맛보기

  • claude.ai에서 새 대화 열기
  • 아래 프롬프트 붙여넣기
  • 오른쪽 미리보기 창에서 바로 재생
  • 마음에 들면 Claude Code로 옮겨 mp4로 뽑기
앱에서 15초 맛보기
HTML 파일 하나로 재생되는 15초 모션그래픽을 만들어줘. 주제는 [우리 카페 가을 신메뉴]. 장면 4개: ① 큰 제목이 튀어나오기 ② 메뉴 3개가 카드로 차례로 등장 ③ 가격이 숫자 카운트업 ④ 로고와 "지금 주문하세요". 배경은 [따뜻한 베이지], 전환은 빠르게. 재생 버튼을 누르면 시작하게 해줘.

이럴 땐 이렇게

troubleshooting

자주 막히는 부분을 모았어요

Q다들 비슷한 영상이 나와요
A

레퍼런스 영상을 주세요. 스타일 이름을 말로 설명하는 것보다 "이 영상처럼"이 훨씬 잘 먹혀요.

QClaude 앱에서도 돼요?
A

간단한 건 앱에서도 HTML 미리보기로 돼요. mp4로 뽑고 길게 다듬으려면 Claude Code + Remotion이 편해요.

Q글자가 깨지지 않아요?
A

코드로 그리는 방식이라 영상 생성 AI와 달리 글자가 정확하게 나와요.

QRemotion은 꼭 설치해야 해요?
A

아니요. Claude Code에 "Remotion으로 렌더해줘"라고 하면 Claude가 설치부터 해줘요. 처음 한 번 Node.js만 깔려 있으면 돼요.

Q영상 길이를 늘리고 싶어요
A

"지금 구성 그대로 30초로 늘려줘, 장면 2개 추가"처럼 몇 초·몇 장면을 숫자로 말하세요. 한 번에 1분 이상은 품질이 떨어지기 쉬워요.

Q세로 영상(릴스용)으로 만들 수 있어요?
A

"1080x1920 세로로, 글자는 화면 위쪽 2/3 안에"라고 처음부터 적으세요. 가로로 만든 뒤 바꾸면 배치가 어색해져요.

tips

    처음엔 15초 쇼릴부터. 짧을수록 한 번에 잘 나와요.

    마음에 안 드는 장면은 "3번 장면만 다시"처럼 콕 집어서 고치세요.

  3. 3

    브랜드 로고·색·폰트를 처음에 같이 주면 "아무 회사 영상"처럼 안 보여요.

용어 풀이

glossary

처음 보는 단어가 있다면

모션그래픽
글자·도형·아이콘이 움직이는 영상. 광고·인트로·설명 영상에 많이 써요.
쇼릴
내 실력을 보여주는 짧은 대표작 모음 영상.
Remotion
React 코드로 영상을 만드는 무료 도구. Claude가 장면을 코드로 쓰고 mp4로 뽑을 때 써요.
렌더
코드·장면을 실제 영상 파일(mp4)로 만들어내는 과정.
스토리보드
영상을 만들기 전에 장면을 그림 몇 장으로 미리 정리한 것.
21st.dev
잘 만들어진 웹 UI 부품(버튼·카드 등)을 모아둔 사이트.
