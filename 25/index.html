모션팀이 3주 걸릴 영상, Opus 5.5는 15분

Claude Opus 5.5는 영상을 "그리는" 대신 영상을 만드는 코드를 써요. 그래서 한 문장으로도 모션그래픽 쇼릴이 나오고, 1,500만 명이 본 서양 문명사 영상도 이렇게 만들어졌어요. 그런데 한 줄만 쓰면 다들 비슷한 결과가 나와요. 원작자들이 공개한 프롬프트와, 결과를 확 바꾸는 4단계 워크플로를 정리했어요.

어떻게 만들어요?

how it works

Claude는 영상을 직접 그리지 않고, 영상을 만드는 코드를 써요

이렇게 작동해요

  1. 1지시한 문장 or 레퍼런스
  2. 2코드 작성HTML·React 장면
  3. 3렌더Remotion 등 → mp4
  4. 4수정한 줄 고치고 다시 렌더

장면마다 코드로 만들기 때문에 글자가 깨지지 않고, "이 부분만 바꿔줘" 하면 그 장면 코드만 고쳐서 다시 렌더해요. 영상 생성 AI처럼 매번 처음부터 뽑지 않아도 돼요.

준비물

  • ClaudeOpus 5.5를 쓸 수 있는 요금제 (Claude 앱 또는 Claude Code — 영상은 Claude Code 추천)
  • 렌더 도구Remotion 또는 HyperFrames — Claude가 코드로 만든 장면을 mp4로 바로 뽑아줘요
  • 레퍼런스 영상따라 하고 싶은 스타일의 영상 1~2개 (whatships.com 같은 런칭 영상 모음에서)
  • 시간쇼릴 15분 정도, 다듬는 시간 포함 1시간이면 충분해요

따라 하는 법

method
01STEP 1

한 문장으로 쇼릴 뽑기 (가장 쉬워요)

  • 원작자가 "한 문장"으로 15분 만에 만든 쇼릴이에요. 모션팀에 맡기면 3~4주, 8,000~10,000달러가 든다고 해요.
  • 쇼릴 프롬프트 (원문)
    make a dynamic 15-second motion graphics video that shows what an incredible motion designer you are, like it's your showreel for a résumé. go all out.
  • 한국어 버전
    네가 얼마나 뛰어난 모션 디자이너인지 보여주는 15초짜리 역동적인 모션그래픽 영상을 만들어줘. 이력서에 넣을 쇼릴처럼. 전력을 다해서.
  • TIP"go all out(전력을 다해)" 같은 한마디가 결과를 꽤 바꿔요. 주제만 바꿔서 "우리 카페 소개 15초 영상"처럼 써도 돼요.
02STEP 2

① 레퍼런스 영상 고르고 ② 렌더 도구 연결

  • 레퍼런스 없이 시키면 Opus는 늘 같은 기본 스타일(가운데 글자, 그라데이션 배경, 페이드 인)로 돌아가요. 그래서 다들 비슷해 보여요.
    1. 1whatships.com 같은 런칭 영상 모음에서 마음에 드는 영상 1~2개 고르기
    2. 2스타일을 말로 설명하지 말고 "이 영상처럼"이라고 레퍼런스를 주기
    3. 3Remotion(또는 HyperFrames) 설치 → Claude가 장면을 코드로 쓰고 mp4로 바로 렌더
    4. 4수정할 땐 "3번 장면 글자만 키워줘"처럼 장면 단위로
  • 레퍼런스 지시
    첨부한 레퍼런스 영상의 속도감, 글자 배치, 전환 방식을 그대로 따라서 (주제) 영상을 만들어줘. Remotion으로 장면마다 코드로 만들고 mp4로 렌더해줘. 길이 20초, 16:9.
03STEP 3

③ 진짜 UI 부품 쓰고 ④ 스토리보드 3개 먼저

  • 제품 화면이 나오는 영상이면 버튼·카드를 Opus가 즉석에서 그리게 두지 마세요. 간격이 어색하고 가짜처럼 보여요.
  • UI 컴포넌트 지시
    영상에 나오는 버튼, 카드, 대시보드 같은 UI는 직접 그리지 말고 21st.dev 컴포넌트를 써줘. 우리 브랜드 색 (색상 코드)과 폰트 (폰트 이름)에 맞춰줘.
  • 스토리보드 먼저
    바로 영상을 만들지 말고, 스토리보드를 3가지 버전으로 먼저 보여줘. 장면마다 정지 화면 1장씩. 내가 고른 버전으로만 영상을 만들어줘.
  • TIP스토리보드 단계에서 고치는 게 렌더된 영상을 고치는 것보다 훨씬 싸고 빨라요.

[주제, 예: 우리 동네 꽃집]을 소개하는 [길이, 예: 15]초짜리 역동적인 모션그래픽 영상을 만들어줘.

- 색: [예: 크림색 배경에 진초록 포인트]

1단계 쇼릴 원문(@leonabboud)을 내 가게·제품용으로 바꿔 쓴 버전

02레퍼런스 영상 따라 만들기 — 분석 먼저
첨부한 레퍼런스 영상을 먼저 분석해줘. 아직 영상은 만들지 마.
1) 장면 길이와 컷 속도 2) 글자 크기·위치·등장 방식 3) 전환 방식 4) 색과 배경 5) 반복되는 리듬 — 이 5가지를 표로 정리해줘.
그다음 이 스타일을 그대로 따라서 [주제, 예: 새로 나온 가계부 앱] 영상 장면 계획을 짜줘.
- 길이 [예: 20]초, 비율 [예: 16:9]
- 꼭 보여줄 것: [예: 앱 이름, 핵심 기능 3개, 다운로드 문구]
내가 계획을 OK 하면 Remotion으로 만들고 mp4로 렌더해줘.

2단계 「레퍼런스 지시」를 분석 → 계획 → 렌더 순서로 나눈 버전 · 레퍼런스 영상 파일이나 화면 녹화를 첨부하세요

03스토리보드 3안 먼저 — 고르고 만들기
[주제, 예: 우리 회사 연말 행사 오프닝] 영상을 만들 거야. 바로 영상을 만들지 말고 스토리보드를 3가지 버전으로 먼저 보여줘.
- 버전마다 분위기를 다르게: [예: ① 미니멀 타이포 ② 빠른 컷 편집 ③ 따뜻한 일러스트풍]
- 버전마다 장면 4~6개, 장면마다 정지 화면 1장 + 한 줄 설명 + 길이(초)
- 전체 길이 [예: 20]초
내가 번호를 고르면 그 버전으로만 Remotion 영상을 만들어서 렌더해줘.

3단계 「스토리보드 먼저」에 분위기·길이 칸을 넣은 버전 · 렌더 전에 고치는 게 훨씬 빨라요

04앱·서비스 런칭 영상 — 진짜 UI 부품으로
[서비스 이름] 런칭 영상을 만들어줘. [서비스 한 줄 소개, 예: 사진을 올리면 가계부를 자동으로 써주는 앱]
- 화면에 나오는 버튼·카드·대시보드는 직접 그리지 말고 21st.dev 컴포넌트를 써줘
- 브랜드 색 [색상 코드, 예: #2F6BFF], 폰트 [폰트 이름, 예: Pretendard]
- 구성: ① 문제 한 줄 ② 앱 화면에서 기능 3개가 차례로 동작 ③ 숫자로 보여주는 효과 ④ 로고 + 다운로드 문구
- 길이 [예: 25]초, 16:9
렌더한 뒤 프레임을 직접 확인해서 글자가 잘리거나 겹치는 곳이 있으면 고치고 다시 렌더해줘.

3단계 「UI 컴포넌트 지시」를 완성형으로 · 숫자는 실제로 확인된 것만 넣으세요

05설명·다큐 영상 — 한 줄 주제로 1분
[주제, 예: 커피가 한국에 들어온 역사]에 대한 [길이, 예: 60]초 설명 영상을 만들어줘.
- 보는 사람: [예: 이 주제를 처음 듣는 20대]
- 먼저 대본을 장면별로 보여줘 (장면 번호 / 화면 / 자막 / 길이)
- 연도·숫자·이름 같은 사실은 확실한 것만 쓰고, 확인이 필요한 건 따로 표시해줘
- 지도·연표·숫자 카운트업처럼 코드로 그리기 좋은 화면을 많이 써줘
대본을 내가 OK 하면 Remotion으로 만들고 mp4로 렌더해줘.

「서양 문명사 영상」 한 줄 지시를 대본 확인 단계가 있는 버전으로 · 사실은 꼭 직접 한 번 더 확인하세요

06릴스용 세로 영상 — 처음부터 세로로
[주제, 예: 이번 주 신상 디저트 3종] 인스타 릴스용 세로 모션그래픽을 만들어줘.
- 1080x1920, [길이, 예: 12]초, 30fps
- 중요한 글자는 화면 위쪽 2/3 안에, 아래쪽은 비워두기 (자막·버튼에 가려지지 않게)
- 첫 1초 안에 [후킹 문구, 예: 「이거 아직 안 먹어봤어요?」]가 크게 등장

렌더한 뒤 장면별 캡처를 보여주고, 글자가 너무 작으면 키워서 다시 렌더해줘.

HTML 파일 하나로 재생되는 15초 모션그래픽을 만들어줘. 주제는 [우리 카페 가을 신메뉴]. 장면 4개: ① 큰 제목이 튀어나오기 ② 메뉴 3개가 카드로 차례로 등장 ③ 가격이 숫자 카운트업 ④ 로고와 "지금 주문하세요". 배경은 [따뜻한 베이지], 전환은 빠르게. 재생 버튼을 누르면 시작하게 해줘.

이럴 땐 이렇게

troubleshooting

자주 막히는 부분을 모았어요

Q다들 비슷한 영상이 나와요
A

레퍼런스 영상을 주세요. 스타일 이름을 말로 설명하는 것보다 "이 영상처럼"이 훨씬 잘 먹혀요.

QClaude 앱에서도 돼요?
A

간단한 건 앱에서도 HTML 미리보기로 돼요. mp4로 뽑고 길게 다듬으려면 Claude Code + Remotion이 편해요.

Q글자가 깨지지 않아요?
A

코드로 그리는 방식이라 영상 생성 AI와 달리 글자가 정확하게 나와요.

QRemotion은 꼭 설치해야 해요?
A

아니요. Claude Code에 "Remotion으로 렌더해줘"라고 하면 Claude가 설치부터 해줘요. 처음 한 번 Node.js만 깔려 있으면 돼요.

Q영상 길이를 늘리고 싶어요
A

"지금 구성 그대로 30초로 늘려줘, 장면 2개 추가"처럼 몇 초·몇 장면을 숫자로 말하세요. 한 번에 1분 이상은 품질이 떨어지기 쉬워요.

Q세로 영상(릴스용)으로 만들 수 있어요?
A

"1080x1920 세로로, 글자는 화면 위쪽 2/3 안에"라고 처음부터 적으세요. 가로로 만든 뒤 바꾸면 배치가 어색해져요.

Q무료로 돼요?
A

Opus 5.5를 쓰려면 그 모델을 쓸 수 있는 Claude 요금제가 필요해요. 어떤 요금제에서 되는지는 Claude 화면의 모델 선택 메뉴에서 확인하세요. Remotion 이용 조건은 Remotion 공식 사이트에서 확인하세요.

Q폰으로도 돼요?
A

Claude 앱에서 HTML 미리보기로 맛보기는 해볼 수 있어요. mp4로 렌더하려면 Claude Code와 Remotion이 돌아가는 컴퓨터가 필요해요.

Q렌더하다가 에러가 나요
A

에러 메시지를 그대로 복사해서 Claude에 붙여넣고 「이 에러 고쳐서 다시 렌더해줘」라고 보내세요. 대부분 Claude가 원인을 찾아 고쳐요.

Q음악도 넣을 수 있어요?
A

쓸 수 있는 음악 파일을 직접 주면 「이 음악에 맞춰 장면을 바꿔줘」처럼 넣을 수 있어요. 저작권이 있는 음악은 올릴 곳의 규정을 먼저 확인하세요.

꿀팁

tips
  1. 1

    처음엔 15초 쇼릴부터. 짧을수록 한 번에 잘 나와요.

  2. 2

    마음에 안 드는 장면은 "3번 장면만 다시"처럼 콕 집어서 고치세요.

  3. 3

    브랜드 로고·색·폰트를 처음에 같이 주면 "아무 회사 영상"처럼 안 보여요.

  4. 4

    스타일은 말로 설명하기보다 레퍼런스 영상 1개를 주는 게 훨씬 정확해요.

  5. 5

    렌더가 끝날 때마다 「프레임을 직접 확인하고 고쳐줘」를 붙이면 글자 잘림 같은 실수를 Claude가 먼저 잡아요.

렌더
코드·장면을 실제 영상 파일(mp4)로 만들어내는 과정.
스토리보드
영상을 만들기 전에 장면을 그림 몇 장으로 미리 정리한 것.
21st.dev
잘 만들어진 웹 UI 부품(버튼·카드 등)을 모아둔 사이트.
Claude Code
컴퓨터 터미널에서 쓰는 Claude. 파일을 직접 만들고 프로그램을 실행할 수 있어서 mp4 렌더까지 해줘요.
Node.js
Remotion 같은 도구를 돌리는 데 필요한 기본 프로그램. 처음 한 번만 설치하면 돼요.
fps
1초에 보여주는 화면 장수. 30fps면 1초에 30장이에요.
컴포넌트
버튼·카드처럼 화면을 만드는 데 다시 쓰는 작은 부품.
