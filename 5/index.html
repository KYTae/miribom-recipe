/코드는 "이런 식으로 답해줘"를 짧게 줄인 신호예요. AI가 코드의 뜻을 짐작해서 반영하는 방식이라, 잘 안 먹히면 코드 뒤에 원하는 걸 한 줄로 풀어 쓰면 확실해요.

이럴 땐 이렇게

troubleshooting

자주 막히는 부분을 모았어요

Q공식 명령어예요?
A

아니에요. AI가 단어 뜻을 알아듣고 반영하는 방식이라 서비스·모델에 따라 반응 정도가 달라요.

Q코드가 안 먹혀요
A

코드 뒤에 원하는 걸 한 줄로 풀어 쓰세요. 예: "/brief 3줄 이내로".

Q여러 개 써도 돼요?
A

2~3개까지는 잘 섞여요. 너무 많이 넣으면 서로 부딪혀요 (예: /brief + /godmode).

Q어디에 붙여요?
A

질문 맨 앞에 붙이세요. 예: "/eli5 금리가 오르면 왜 집값이 떨어져?"

QChatGPT 슬래시 메뉴랑 같은 거예요?
A

아니요. 채팅창에 /를 치면 뜨는 공식 메뉴(이미지, 검색 등)와는 별개예요. 여기 코드는 AI가 단어 뜻을 읽고 따라 하는 "약속어"예요.

꿀팁

tips
  1. 1

    자주 쓰는 코드는 "맞춤 지침"에 "/brief라고 쓰면 3줄로 답해줘"처럼 뜻까지 적어두면 더 정확해져요.

  2. 2

    코드 두 개까지는 같이 써도 잘 먹혀요. 예: /eli5 /table

  3. 3

    코드가 안 먹히면 코드 뒤에 원하는 형식을 한 줄 덧붙이세요. 예: "/brief 3줄로".
