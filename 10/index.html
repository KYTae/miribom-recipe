어떻게 영상이 나와요?

how it works

그림이 아니라 코드로 만든 영상이에요

이렇게 작동해요

  1. 1프롬프트 한 줄영어 그대로
  2. 2AI가 코드 작성애니메이션을 코드로
  3. 3렌더링코드를 영상 파일로
  4. 4MP4 완성수정 요청 반복

이미지 AI처럼 그림을 생성하는 게 아니라, AI가 애니메이션 코드를 직접 짜고 그걸 영상 파일로 렌더링해요. 그래서 글자가 깨지지 않고 선명해요.

준비물

  • Claude Code코드를 직접 실행할 수 있는 AI (유료 요금제 필요)
  • 빈 폴더 하나바탕화면에 "showreel" 같은 새 폴더
  • 모델·추론 강도가장 높은 모델, 추론 강도 높게 (결과 차이가 커요)
  • 시간한 번에 10~30분 정도

따라 하는 법

method
01STEP 1

Claude Code 설치하고 폴더 열기

  • 공식 안내에 따라 Claude Code를 설치해요. 설치가 끝나면 터미널에서 빈 폴더로 이동해 claude를 실행해요.
  • 터미널에서
    mkdir showreel && cd showreel && claude
  • TIP설치 방법은 공식 문서(https://docs.claude.com/en/docs/claude-code/overview)에 운영체제별로 나와 있어요.
02STEP 2

프롬프트 붙여넣기

  • 영어 그대로 넣는 게 결과가 좋아요. "go all out(전력을 다해)" 한마디가 퀄리티를 확 끌어올려요.
  • 원작 프롬프트
    make a dynamic 15-second motion graphics video that shows what an incredible motion designer you are, like it's your showreel for a résumé. go all out.
  • 주의중간에 "이 명령 실행해도 될까요?"라고 물어보면 내용을 읽고 허락해 주세요. 렌더링에 필요한 프로그램을 설치하는 경우가 많아요.
03STEP 3

MP4로 받고 고치기

  • 끝나면 폴더 안에 영상 파일이 생겨요. 안 보이면 "결과를 MP4로 렌더링해서 이 폴더에 저장해줘"라고 하세요.
    1. 1"전환을 더 빠르게"
    2. 2"3D 느낌을 더 강하게"
    3. 3"마지막에 내 이름이 크게 나오게"
  • TIP한 번에 다 바꾸지 말고 하나씩 요청하면 원하는 방향으로 빨리 가요.

이럴 땐 이렇게

troubleshooting

자주 막히는 부분을 모았어요

Q무료로는 못 해요?
A

Claude Code는 유료 요금제가 필요해요. 무료로 맛보기를 하려면 Claude나 ChatGPT 웹에서 "HTML 애니메이션으로 만들어줘"라고 하면 브라우저에서 움직이는 결과를 볼 수 있어요 (MP4 파일은 아님).

Q렌더링에서 에러가 나요
A

에러 메시지를 그대로 붙여넣고 "이 에러 해결하고 다시 렌더링해줘"라고 하면 대부분 스스로 고쳐요.

Q결과가 매번 달라요
A

정상이에요. 마음에 드는 결과가 나오면 그 폴더를 통째로 저장해 두세요. 코드가 남아 있어서 나중에 고치기 쉬워요.

QClaude 앱(웹)에서 해도 돼요?
A

미리보기로 움직이는 화면은 볼 수 있어요. mp4 파일로 받으려면 Claude Code가 필요해요.

꿀팁

tips
  1. 1

    원작 프롬프트는 영어 그대로 넣는 게 가장 잘 나와요. 내 브랜드 버전은 아래 "브랜드·용도별"을 쓰세요.

  2. 2

    "go all out(전력을 다해)" 한마디가 결과를 꽤 바꿔요. 지우지 마세요.

  3. 3

    마음에 드는 장면이 나오면 "3번 장면만 남기고 나머지를 이 스타일로 다시"처럼 좋은 부분을 기준으로 고치세요.
