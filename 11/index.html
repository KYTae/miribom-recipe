JSON은 "주인공", "조명", "카메라"처럼 칸을 나눠 적는 형식이에요. 칸이 정해져 있으니 빠뜨리는 게 없고, 한 칸만 바꿔서 다시 만들기도 쉬워요.

준비물

  • 영상 AISeedance(드리미나·CapCut·invideo 등에서 사용) 또는 다른 영상 AI
  • 챗봇 하나ChatGPT·Claude 무료 버전으로 JSON 변환
  • 값은 영어로칸 이름과 값은 영어가 결과가 안정적이에요

JSON 프롬프트

prompt pack

누르면 바로 복사돼요 · 상황별로 골라 쓰세요

실전 프롬프트 — [ ]만 바꿔서 쓰기

JSON은 영상 AI(Seedance·Kling·Higgsfield 등) 입력칸에, 한국어 프롬프트는 ChatGPT·Claude에 · 미리봄이 만든 예시예요

01JSON 기본 틀 — 빈칸 버전 (영상 AI에)
{
  "subject": "[hero, e.g. a corgi in a yellow raincoat]",
  "environment": "[place + time, e.g. a quiet beach at dawn]",
  "camera": "[ONE move only, e.g. slow push-in]",
  "lighting": "[light, e.g. soft golden hour backlight]",
  "mood": "[feeling, e.g. calm and nostalgic]",
  "motion": "[action, e.g. the corgi shakes off water]",
  "color_grade": "[color look, e.g. warm film]",
  "duration": "5 seconds",
  "aspect_ratio": "9:16 vertical"
}

[ ] 안을 지우고 영어로 내 장면을 적어요. 길이·비율 칸은 쓰는 서비스가 지원하는 값으로 바꾸세요

02컷 나누기 확장판 — 초 단위 3컷
{
  "subject": "[who, e.g. a barista with short hair]",
  "outfit": "[clothes, e.g. green apron, white shirt]",
  "environment": "[place, e.g. a small cafe, rainy evening]",
  "shots": [
    {"time": "0-3s", "shot": "wide shot", "action": "[e.g. she wipes the counter]"},
    {"time": "3-6s", "shot": "medium shot", "action": "[e.g. she looks up and smiles]"},
    {"time": "6-9s", "shot": "close-up", "action": "[e.g. latte art being poured]"}
  ],
  "camera": "slow dolly-in, stable",
  "lighting": "warm practical lights, rain reflections on the window",
  "consistency": "same person, same outfit, same cafe in every shot",
  "avoid": "text, logos, extra people, warped hands"
}

한 영상 안에 컷을 나누고 싶을 때. 인물·옷 칸을 따로 두면 컷이 바뀌어도 사람이 덜 바뀌어요

03제품 소개 영상 — 쇼핑몰·SNS용
{
  "subject": "[product, e.g. a bottle of citrus soda]",
  "environment": "[background, e.g. a pastel mint studio]",
  "camera": "[ONE move, e.g. slow 180-degree orbit]",
  "lighting": "soft key light from the left, crisp rim light, subtle reflections",
  "motion": "[motion, e.g. water droplets slide down]",
  "mood": "premium and minimal",
  "color_grade": "[brand colors, e.g. mint and white]",
  "avoid": "other brand logos, random text, hands, clutter"
}

내 제품 이름·색만 바꾸면 돼요. 다른 회사 로고·제품을 그대로 넣지는 마세요

04일상 브이로그 — 사람이 나오는 장면
{
  "subject": "[person, e.g. a woman in her 20s]",
  "outfit": "[e.g. gray hoodie, white sneakers]",
  "environment": "[e.g. a bakery street in the morning]",
  "camera": "handheld tracking shot at walking speed, slight natural shake",
  "lighting": "[e.g. soft overcast daylight]",
  "motion": "[e.g. she buys a croissant and bites it]",
  "mood": "cozy, everyday, unposed",
  "color_grade": "natural colors, not cinematic",
  "consistency": "same face, hairstyle and outfit from start to end"
}

실존 인물·연예인 이름은 넣지 말고 나이·머리·옷처럼 모습만 묘사하세요

05챗봇에 — 내 아이디어를 JSON 3가지 버전으로
아래 영상 아이디어를 AI 영상용 JSON 프롬프트로 바꿔줘.
- 아이디어: [한국어로 장면 설명, 예: 비 오는 밤 편의점 앞 고양이]
- 칸: subject, environment, camera, lighting, mood, motion, color_grade (값은 모두 영어)
- 카메라 움직임은 버전마다 딱 1개씩, 서로 다르게: 버전 A slow push-in / 버전 B orbit / 버전 C tracking
- 길이 [5]초, 화면 비율 [9:16 세로]
JSON 3개를 각각 코드 블록으로 주고, 마지막에 세 버전이 어떻게 다르게 보일지 한국어로 한 줄씩 설명해줘.

ChatGPT·Claude 무료 버전에 붙여넣기 — 기존 변환 프롬프트를 3버전 비교용으로 바꾼 것

06챗봇에 — 결과 보고 JSON 고치기
내가 영상 AI에 넣은 JSON과 결과가 아래에 있어. 결과에서 아쉬운 점만 고쳐서 JSON을 다시 써줘.
- 아쉬운 점: [예: 카메라가 너무 빨리 돌고, 고양이 얼굴이 중간에 바뀜]
- 바꾸면 안 되는 것: [예: 장소와 색감은 그대로]
고친 칸만 표로 보여줘 (칸 이름 · 바꾸기 전 · 바꾼 후 · 이유). 그 다음 전체 JSON을 코드 블록으로 줘.

[내가 넣은 JSON 붙여넣기]

한 번에 다 바꾸지 않고 문제 칸만 고치게 해요

07챗봇에 — 같은 톤으로 시리즈 만들기
아래 JSON은 마음에 드는 결과가 나온 프롬프트야. camera, lighting, mood, color_grade 칸은 한 글자도 바꾸지 말고, subject와 motion만 바꿔서 시리즈 [4]편을 만들어줘.
- 시리즈 주제: [예: 사계절 속 같은 고양이]
- 편마다 subject와 motion이 겹치지 않게
JSON [4]개를 코드 블록으로 주고, 각 편 제목을 한국어로 붙여줘.

[마음에 든 JSON 붙여넣기]

릴스 시리즈처럼 톤이 일정해야 할 때

08JSON이 안 먹힐 때 — 칸 이름 줄글 버전
Subject: [main character, e.g. a small orange cat].
Environment: [place, e.g. a narrow alley after rain].
Camera: [ONE move, e.g. low tracking shot].
Lighting: [e.g. neon light, wet reflections].
Mood: [e.g. cozy and cinematic].
Motion: [e.g. the cat walks toward the camera].
Color grade: [e.g. warm film].
No text, no logos, no extra animals.

중괄호 { }를 이상하게 읽는 서비스라면 같은 내용을 이렇게 줄 단위로 넣어보세요

이럴 땐 이렇게

troubleshooting

자주 막히는 부분을 모았어요

QJSON 문법이 틀리면요?
A

괄호 { }, 따옴표 " ", 쉼표만 지키면 돼요. 헷갈리면 챗봇에 "이 JSON 문법 맞는지 확인해줘"라고 하세요.

Q일반 문장보다 무조건 좋아요?
A

아니에요. 일반 프롬프트도 좋은 결과가 나와요. 원하는 장면을 정확히, 여러 번 같은 톤으로 뽑고 싶을 때 JSON이 유리해요.

Q카메라 움직임을 여러 개 넣으면요?
A

화면이 흔들리거나 어색해지기 쉬워요. 한 영상에 하나만 넣는 게 좋아요.

Q모든 영상 AI가 JSON을 알아들어요?
A

대부분 글로 읽기 때문에 칸 이름과 값을 그대로 이해해요. 안 먹히면 같은 내용을 "Subject: …, Camera: …"처럼 줄글로 바꿔도 비슷한 효과가 나요.

Q어디에 붙여요?
A

영상 AI의 프롬프트(글 입력) 칸에 JSON을 맨 앞 { 부터 맨 끝 } 까지 통째로 붙여넣어요. 챗봇용 한국어 프롬프트는 ChatGPT나 Claude 대화창에 넣어요.

Q[ ] 괄호랑 e.g. 예시도 같이 넣어요?
A

아니요. [ ]와 e.g. 부분은 지우고 내 내용만 남기세요. 예: "[hero, e.g. a corgi]" → "a corgi in a yellow raincoat"

Q무료로 해볼 수 있어요?
A

JSON 만들기는 ChatGPT·Claude 무료 버전으로 충분해요. 영상 생성은 서비스마다 무료 크레딧 여부가 달라서 쓰는 앱 화면에서 확인하세요.

Q폰으로도 돼요?
A

돼요. 챗봇 앱에서 JSON을 복사해 영상 AI 앱 입력칸에 붙여넣으면 돼요. 줄바꿈이 사라져서 한 줄로 붙어도 내용은 똑같이 읽혀요.

Q입력칸에 글자 수가 넘친다고 나와요
A

값을 짧게 줄이세요. 챗봇에 "이 JSON을 뜻은 그대로 두고 절반 길이로 줄여줘"라고 하면 돼요. avoid 칸부터 빼도 괜찮아요.

Q값을 한국어로 써도 돼요?
A

알아듣는 경우도 많지만 영어가 결과가 더 안정적이에요. 한국어로 아이디어만 쓰고 챗봇에 영어 JSON으로 바꿔 달라고 하세요.

꿀팁

tips
  1. 1

    "epic, amazing" 같은 막연한 단어 대신 golden hour, slow orbit처럼 구체적인 단어를 쓰세요.

  2. 2

    틀은 그대로 두고 subject만 바꾸면 시리즈 영상의 톤이 일정하게 유지돼요.

  3. 3

    마음에 드는 결과가 나오면 그 JSON을 꼭 저장해 두세요.

  4. 4

    [ ] 괄호와 e.g. 예시는 지우고 내 내용만 남기세요. 괄호째 넣으면 AI가 헷갈려요.

  5. 5

    다시 만들 땐 칸을 하나씩만 바꾸세요. 그래야 무엇 때문에 좋아졌는지 알 수 있어요.
