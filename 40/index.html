Claude에 연결하면 달라지는 앱 5가지 — HyperFrames·Fusion·Blender·Adobe·Ableton

01STEP 1HyperFrames

01 HyperFrames — HTML을 영상으로

  • HeyGen이 공개한 오픈소스로, HTML·CSS·애니메이션을 MP4 영상으로 렌더링해요. Claude Code 플러그인으로 설치하면 Claude가 장면을 짜고, 렌더링하고, 결과 프레임까지 확인할 수 있어요. 원작자는 이 셋업을 소개하며 뇌 그래픽 모션 영상을 함께 올렸어요. Claude Code 폴더 하나에 HyperFrames·Remotion·GSAP·모션 디자인 스킬·Blender를 붙이면 기획하고, 움직이고, 렌더링하고, 보여주기 전에 자기 프레임까지 확인한다고 설명해요.
  • Claude Code에 설치 (공식 README)
    claude plugin marketplace add heygen-com/hyperframes
claude plugin install hyperframes@hyperframes
  • 미리봄 한국어 예시
    /hyperframes:hyperframes
우리 서비스를 소개하는 15초 세로 영상(1080×1920)을 만들어줘.
- 첫 2초: 큰 제목이 튀어나오는 장면
- 가운데: 기능 3가지를 카드로 하나씩
- 마지막: 로고와 한 줄 문구
렌더링한 뒤 프레임을 직접 확인하고, 글자가 잘리면 고쳐서 다시 렌더링해줘.
  • TIP깃허브 스타 6.97만 (2026년 10월 22일 기준). 설치 후 /hyperframes:hyperframes로 불러요.
02STEP 2Fusion

02 Autodesk Fusion — "분해도 만들어줘"

  • Fusion 커넥터를 쓰면 대화로 3D 모델을 만들고 고칠 수 있어요. 영상에서는 부품 1,235개짜리 키보드 설계를 열어 두고 "분해도 만들어줘"라고 하자, Claude가 케이스·PCB·플레이트·키를 층층이 띄워 분해도를 만들었어요.
  • 영상 속 프롬프트 1 (원문)
    Can you look at my design in Fusion? I need you to arrange the keys properly on the keyboard.
  • 영상 속 프롬프트 2 (원문)
    Can you move the main components vertically to create an exploded view?
  • 미리봄 한국어 버전
    Fusion에 열린 내 디자인 좀 봐줘. 주요 부품을 위아래로 띄워서 분해도(exploded view)를 만들어줘.
층 사이 간격은 고르게 맞춰주고, 끝나면 어떤 순서로 쌓였는지 알려줘.
  • 주의Fusion 구독이 있어야 쓸 수 있어요.
03STEP 3Blender

03 Blender — 돌 185개 재질을 말 한마디로

  • Blender 개발자들이 직접 만든 공식 커넥터예요. Blender의 Python API를 말로 다룰 수 있게 해줘서, 씬 전체를 분석·디버그하거나 오브젝트 수백 개를 한 번에 고치고, Blender 메뉴에 새 도구를 추가할 수도 있어요.
  • 영상에서는 이름에 "rock"이 들어간 돌 185개를 찾아, 기준 돌과 같은 재질로 한 번에 통일했어요. 새 재질은 하나도 만들지 않았어요.
    1. 1Claude 데스크톱 → Customize → Connectors → Blender 검색 → Add
    2. 2blender.org/lab/mcp-server 페이지의 설치 링크를 Blender 창으로 드래그 (lab 저장소 허용)
    3. 3같은 링크를 한 번 더 드래그해 애드온 설치
    4. 4Edit → Preferences → Add-ons → BlenderMCP에서 MCP 서버 시작 (작업할 때마다)
  • 영상 속 프롬프트 (원문)
    Find the object named "rock_textured" and use it as the material reference.
Select all other mesh objects in the scene whose names contain "rock" (excluding "rock_textured").
Assign the exact same material(s) from "rock_textured" to all selected objects.
Ensure no new materials are created - reuse the existing material data.
Do not change geometry, transforms, or any other properties.
  • 미리봄 한국어 버전
    이름이 "rock_textured"인 오브젝트를 재질 기준으로 삼아줘.
이름에 "rock"이 들어간 나머지 메시 오브젝트를 모두 선택하고("rock_textured" 제외),
"rock_textured"와 똑같은 재질을 전부 적용해줘.
새 재질은 만들지 말고 기존 재질 데이터를 그대로 재사용해.
모양·위치·크기 같은 다른 속성은 건드리지 마.
  • 주의브라우저(claude.ai)에서는 안 돼요. Blender가 켜진 같은 컴퓨터의 Claude 데스크톱이 필요해요. 변경은 Blender에서 저장해야 파일에 남아요.
04STEP 4Adobe

04 Adobe for creativity — 포토샵을 채팅으로

  • Adobe 공식 커넥터로, 포토샵·프리미어·익스프레스 등 Creative Cloud의 50개 넘는 도구를 Claude 채팅에서 불러 쓸 수 있어요. 영상에서는 디렉터리에서 Adobe를 검색해 연결한 뒤, 사진 한 장으로 필터가 다른 4장을 만들어 Firefly Boards 무드보드로 정리했어요.
  • 영상 속 프롬프트 (원문)
    Create a mood board inspired by this image in Firefly Boards
  • 미리봄 한국어 버전
    (사진 첨부) 이 사진으로 필터를 다르게 적용한 버전 4장을 만들어서
Firefly Boards에 무드보드로 정리해줘.
  • TIP영상 마지막의 무드보드 결과에는 실제 인물 사진이 나와서 미리봄 영상에서는 잘라냈어요.
05STEP 5Ableton

05 Ableton MCP — 프롬프트 2번에 신스웨이브

  • Blender MCP도 만든 Siddharth Ahuja가 공개한 오픈소스 연결이에요. Claude가 Ableton Live에 트랙을 만들고, 악기를 불러오고, 멜로디와 이펙트까지 직접 넣어요. 원작자는 프롬프트 2번으로 80년대 신스웨이브 트랙을 만들었다고 밝혔어요(2025년 3월, Claude 3.7 Sonnet).
  • 영상 속 프롬프트 (원문)
    Create a lush 80s style synthwave track
  • 미리봄 한국어 버전
    80년대 느낌의 풍성한 신스웨이브 트랙을 만들어줘.
베이스·패드·리드·드럼을 각각 트랙으로 나누고, 리버브와 딜레이도 걸어줘.
  • 주의헷갈리기 쉬운 점: 2026년 4월에 나온 Ableton 공식 커넥터는 Live·Push 공식 매뉴얼을 근거로 답해주는 용도예요. 작곡까지 하는 건 이 오픈소스 연결이에요.

이럴 땐 이렇게

troubleshooting

자주 막히는 부분을 모았어요

Q무료 플랜도 되나요?
A

Blender 커넥터는 무료 포함 모든 플랜에서 Claude 데스크톱으로 쓸 수 있어요(Claude 튜토리얼 기준). Fusion은 Fusion 구독이 필요해요.

Q브라우저(claude.ai)에서도 되나요?
A

Blender처럼 내 컴퓨터 프로그램을 다루는 연결은 Claude 데스크톱이 필요해요.

Q커넥터와 플러그인은 뭐가 달라요?
A

커넥터는 Claude를 다른 앱에 연결하는 통로예요. 플러그인은 Claude Code에 스킬·명령어 등을 묶어 설치하는 꾸러미예요. HyperFrames는 플러그인이에요.

Q연결했는데 Claude가 Blender를 못 찾아요
A

Blender 안에서 Edit → Preferences → Add-ons → BlenderMCP의 MCP 서버를 켰는지 확인하세요. 작업할 때마다 켜야 해요. 대화창 왼쪽 아래 + → Connectors에서 Blender가 켜져 있는지도 보세요.

QClaude가 내 파일을 망가뜨리면 어떡해요?
A

처음엔 복사본으로 작업하고, 프롬프트 끝에 "실행 전에 바꿀 목록부터 보여줘"를 붙이세요. Blender는 저장해야 파일에 남아요.

QAbleton 공식 커넥터로 작곡이 되나요?
A

아니요. 2026년 4월 공식 커넥터는 Live·Push 매뉴얼을 근거로 답해주는 용도예요. 영상 속 작곡은 오픈소스 Ableton MCP예요.

Q어떤 앱부터 연결해볼까요?
A

Blender가 무료라 가장 쉬워요. 이미 쓰는 앱이 있다면 그 앱 커넥터부터 연결하세요.

꿀팁

tips
  1. 1

    공식 커넥터는 Customize → Connectors에서 검색해서 추가.

  2. 2

    Blender는 작업할 때마다 MCP 서버를 켜기.

  3. 3

    큰 작업 전엔 원본 파일을 따로 저장해두기.

  4. 4

    프롬프트 끝에 "실행 전에 목록부터 보여줘"를 붙이면 실수가 확 줄어요.

  5. 5

    숫자를 말할 땐 단위(mm, px, 초)까지 같이 적으세요.
