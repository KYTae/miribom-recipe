how to use

모든 레시피가 같은 순서예요

  1. 1"처음이라면" 칸과 준비물부터필요한 계정·사진·시간을 먼저 확인해요. 무료로 되는지도 여기 적혀 있어요.
  2. 2복사 버튼 → 붙여넣기프롬프트 오른쪽 위 복사를 누르고, "붙여넣을 곳"에 적힌 사이트에 붙여넣어요.
  3. 3[ ] 만 바꾸기대괄호 안을 내 상황으로 바꿔요. 대괄호 기호는 지워도 되고 그대로 둬도 돼요.
  4. 4막히면 "이럴 땐 이렇게"레시피 아래쪽에 자주 막히는 문제와 고치는 법을 모아뒀어요.

faq
Q정말 무료로 돼요?
A

ChatGPT·Claude·Gemini는 무료로 시작할 수 있어요. 최신 모델이나 많이 쓰면 유료 요금제가 필요해요. 영상·이미지 AI는 무료 크레딧을 먼저 주고, 다 쓰면 충전하는 방식이 많아요.

Q영어를 못해도 돼요?
A

네. 대부분 한국어로 써도 잘 알아들어요. 영상·이미지 AI는 영어 프롬프트가 조금 더 정확해서, 미리봄 레시피는 영어 원문과 한국어를 함께 넣어둬요.

Q폰으로만 해도 돼요?
A

대부분 돼요. ChatGPT·Claude·Gemini·Kling 모두 앱이나 모바일 웹이 있어요. Claude Code처럼 "내 컴퓨터에서 실행"하는 도구만 PC가 필요해요.

Q결과가 매번 달라요
A

정상이에요. AI는 같은 문장에도 조금씩 다른 답을 줘요. 2~3번 다시 만들어 보고 마음에 드는 걸 고르세요.

Q회사 자료나 내 얼굴 사진을 넣어도 돼요?
A

회사 기밀·고객 정보는 회사가 허락한 AI에만 넣으세요. 본인 사진은 괜찮지만, 다른 사람 사진은 허락 없이 쓰면 안 돼요.

QAI로 만든 걸 SNS에 올려도 돼요?
A

올려도 돼요. 인스타·틱톡·유튜브는 AI로 만든 사람·장면에 "AI 정보" 표시를 요구해요. 남의 노래·캐릭터를 쓰면 저작권 문제가 생길 수 있어요.
