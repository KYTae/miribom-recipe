신비한 AI 사전 No.1 퍼셉트론 — 빛 센서 400개와 손잡이 512개로 배우던 기계 (1958)

1958년 7월, 미 해군 연구청(ONR)이 워싱턴에서 기자들에게 “스스로 배우는 기계”를 공개했어요. 코넬 항공연구소의 심리학자 프랭크 로젠블랫이 만든 퍼셉트론이에요. 첫 시연은 IBM 704에서 돌아간 프로그램이었고, 카드 왼쪽·오른쪽 표시를 50번 만에 스스로 구별했어요. 2년 뒤 공개된 Mark I 퍼셉트론은 카메라 필름 자리에 빛 센서 400개(20×20)를 달고, 모터가 돌리는 가변저항(손잡이)의 위치에 기억을 담았어요. 지금 말로 하면 가중치예요. 영상은 실제 기록 화면이 아니라 AI(Veo 3.1)로 재구성했고, 화면 속 숫자와 글자는 전부 편집에서 따로 넣었어요.

01STEP 11958

1958년 7월 — “스스로 배우는 기계”의 공개

  • 미 해군 연구청(ONR)이 워싱턴에서 기자들 앞에 퍼셉트론을 공개했어요. 첫 시연은 기상청이 쓰던 IBM 704(방 하나를 채우는 크기) 위에서 돌아간 시뮬레이션 프로그램이었어요.
    1. 1카드 왼쪽 또는 오른쪽에 표시가 있는 카드를 보여줌
    2. 250번 시도 끝에 왼쪽·오른쪽을 스스로 구별
    3. 3다음 날 뉴욕타임스 “NEW NAVY DEVICE LEARNS BY DOING”
  • TIP기사에는 해군이 이 기계를 “언젠가 걷고, 말하고, 보고, 쓰고, 스스로를 복제하고, 자기 존재를 의식하게 될 전자 컴퓨터의 배아(embryo)”로 기대한다는 문장이 실렸어요.
02STEP 2Mark I

1960년 Mark I — 카메라 필름 자리에 빛 센서 400개

  • Mark I 퍼셉트론은 실제로 만든 기계예요. 개조한 뷰 카메라의 필름 자리에 빛 센서(광저항) 400개를 20×20으로 박아 “눈”으로 썼어요. 1960년 운용 매뉴얼 기준 연상 유닛(A-unit) 512개, 응답 유닛(R-unit) 8개 구성이에요.
  • 구조 한 줄씩
    • 빛 센서 400개 = 입력(눈)
    • 연상 유닛 512개 = 중간 계산
    • 응답 유닛 8개 = 출력
    • 센서와 연상 유닛 연결은 무작위로 고정, 학습은 연상 → 응답 쪽에서
03STEP 3가중치

손잡이 512개의 각도 = 기계의 기억 = 가중치

  • 틀릴 때마다 작은 직류 모터가 가변저항(포텐셔미터)을 돌려 값을 조금씩 바꿨어요. 매뉴얼은 “512개 연상 유닛의 가변저항 위치가 퍼셉트론의 기억”이라고 적고 있어요. 지금 신경망의 가중치(weight)와 같은 역할이에요.
  • TIP영상 속 “손잡이”가 바로 이 가변저항이에요. 사람이 돌리는 게 아니라 모터가 학습 규칙에 따라 돌렸어요.
04STEP 4겨울과 부활

겨울, 그리고 다시 깨어난 손잡이들

  • 1969년 민스키와 패퍼트의 책 《Perceptrons》가 한 층짜리 퍼셉트론이 풀 수 없는 문제를 수학으로 보여줬고, 그 뒤 신경망 연구는 한동안 침체했어요. 로젠블랫은 1971년 7월 11일, 43번째 생일에 보트 사고로 세상을 떠났어요.
  • 1986년 역전파(backpropagation) 논문이 Nature에 실리면서, 손잡이를 여러 층으로 쌓고 한꺼번에 조정하는 방법이 널리 퍼졌어요. 2020년 GPT-3에는 이런 파라미터가 1,750억 개 있어요.
  • 주의“책 한 권 때문에 AI 겨울이 왔다”는 말은 과장이에요. 책이 나온 뒤 연구가 침체한 건 사실이지만, 자금·컴퓨터 성능 등 여러 이유가 겹쳤다고 보는 게 정확해요.
05STEP 5만들어보기

직접 만들어보기 — 손잡이가 돌아가며 배우는 퍼셉트론

  • 아래 영어 프롬프트를 Claude에 그대로 붙여 넣으면, 20×20 빛 센서와 손잡이(가중치)가 돌아가며 왼쪽·오른쪽을 배우는 데모 페이지를 만들어줘요. 50번 안팎에서 맞히기 시작하는지 직접 확인해보세요.
  • 브라우저 퍼셉트론 데모 (영어)
    Build a single-file HTML page (no libraries, no build step) that teaches how the 1958 Perceptron learned.

1) Left: a 20 x 20 grid of "light sensors" (400 cells). I can paint cells with the mouse or finger, and there is a "random card" button that draws one dark square either on the left half or the right half.
2) Middle: a single-layer perceptron with 400 inputs (+ bias). Draw every weight as a small round knob whose rotation angle shows the weight value (clockwise = positive, counter-clockwise = negative).
3) Buttons: "Train 1 step" and "Train 50 steps". On each mistake, rotate the knobs a little with the perceptron learning rule and animate the knobs turning, like small motors.
4) Show a counter: trial number and how many of the last 20 were correct. The goal is to learn LEFT vs RIGHT within about 50 trials.
5) Right: "Test" mode - I paint a card and the page says LEFT or RIGHT with its confidence.
6) Add one short caption in Korean under each panel explaining what it is. Dark theme, warm orange accents, works on a phone screen.
  • 쉽게 설명 듣기 (한국어)
    퍼셉트론을 중학생도 이해하게 설명해줘.
- 빛 센서(입력), 손잡이(가중치), 합쳐서 기준을 넘으면 켜지는 전구(출력)로 비유해서
- 틀렸을 때 손잡이를 어떻게 돌리는지(학습 규칙)를 숫자 예시 하나로
- 한 층짜리 퍼셉트론이 못 하는 일(예: XOR)이 왜 생기는지 그림 없이 말로
- 마지막에 지금의 신경망(여러 층 + 역전파)과 무엇이 같고 무엇이 다른지 3줄로
  • TIP“Train 1 step”을 여러 번 눌러 손잡이가 틀릴 때만 돌아가는 걸 보면, 퍼셉트론 학습 규칙이 한 번에 이해돼요.
    1. 1Claude 대화창에 데모 프롬프트를 붙여 넣고 보내기
    2. 2만들어진 페이지(아티팩트)에서 random card → Train 1 step 순서로 눌러보기
    3. 3안 움직이면 증상을 그대로 적어 고쳐달라고 이어 보내기

02손으로 따라 하는 학습 규칙 연습
퍼셉트론이 「틀리면 손잡이를 조금 돌린다」는 걸 숫자로 직접 따라 해보고 싶어.
- 입력 [개수, 예: 2]개짜리 아주 작은 퍼셉트론, 처음 가중치는 모두 0, 학습률은 [예: 1]
- 배울 규칙: [예: 두 입력이 모두 1일 때만 켜기(AND)]
- 틀릴 때마다 가중치가 어떻게 바뀌는지 표로 보여줘 (회차 · 입력 · 정답 · 예측 · 바뀐 가중치)
- 모두 맞힐 때까지 계속하고, 마지막에 같은 방법으로 XOR은 왜 끝나지 않는지 한 문단으로
계산은 한 줄씩 보여주고, 어려운 기호는 쓰지 마.

숫자로 한 번 해보면 학습 규칙이 바로 이해돼요

03데모 바꿔 만들기 (영어 · Claude)
Build a single-file HTML page (no libraries, no build step) that teaches how a single-layer perceptron learns.

1) Input: a [grid size, e.g. 10 x 10] grid of "light sensors" that I can paint with the mouse or a finger.
2) Task: learn [two classes, e.g. TOP vs BOTTOM] from example cards. Add one "random card" button for each class.
3) Draw every weight as a small round knob whose angle shows its value. Animate the knobs turning only when the answer is wrong, like small motors.
4) Buttons: "Train 1 step", "Train [number, e.g. 20] steps", "Reset". Show the trial count and how many of the last 20 were correct.
5) Add a "hard mode" with [hard task, e.g. ON if only one side dark] so I can see that a single layer never fully learns it, with one Korean sentence explaining why.
6) Short Korean captions under each panel. Dark theme, works on a phone screen.

이럴 땐 이렇게

troubleshooting

자주 막히는 부분을 모았어요

Q영상이 실제 기록 화면이에요?
A

아니요. Veo 3.1로 만든 재구성 영상이에요. 실존 인물의 얼굴은 만들지 않았고, 화면 속 숫자·이름·신문 제목은 편집에서 따로 넣었어요. Mark I 실물은 스미스소니언 국립미국역사박물관이 소장하고 있어요.

QMark I이 방 하나만 했어요?
A

방 하나 크기였던 건 1958년 첫 시연에 쓴 IBM 704예요. Mark I은 사람 키만 한 캐비닛으로 된 별도 기계예요.

Q손잡이가 정확히 512개예요?
A

1960년 운용 매뉴얼은 “512개 연상 유닛의 가변저항 위치가 기억”이라고 적어요. 다만 Mark I은 버전마다 유닛 수가 달랐다는 기록도 있어서, 512는 매뉴얼 기준 숫자예요.

QXOR 문제가 뭐예요?
A

두 입력 중 “하나만” 켜졌을 때 켜지는 규칙이에요. 한 층짜리 퍼셉트론은 직선 하나로만 나눌 수 있어서 이걸 풀지 못해요. 여러 층을 쌓으면 풀 수 있어요.

Q프롬프트는 어디에 붙여요?
A

한국어 프롬프트와 데모(영어) 프롬프트는 Claude나 ChatGPT 대화창에 붙여요. Veo용 영어 프롬프트는 구글 Flow의 프롬프트 칸에 붙여요.

Q무료로 돼요?
A

설명 듣기·대본·데모는 Claude·ChatGPT 무료 플랜으로도 시작할 수 있어요(쓸 수 있는 양에 제한이 있어요). Veo 영상은 Flow 크레딧을 써요. 요금제와 남은 크레딧은 Flow 화면에서 확인하세요.

Q폰으로도 돼요?
A

설명 듣기와 대본 쓰기는 폰 앱으로 충분해요. 데모 페이지도 폰 화면에 맞게 만들라고 프롬프트에 적어 뒀어요. 컷을 이어 붙이고 자막을 얹는 편집은 컴퓨터가 편해요.

QVeo 영상에 글자가 자꾸 생겨요
A

프롬프트에서 날짜·이름·숫자를 빼고 끝에 No text… 문장을 꼭 넣으세요. 그래도 생기면 글자가 없는 구간만 잘라 쓰거나, 확대해서 잘라내세요.

Q데모 페이지가 안 움직여요
A

버튼이 안 눌리거나 화면이 비어 있으면, 보이는 증상과 오류 문장을 그대로 복사해 「이렇게 나와. 고쳐줘」라고 이어 보내세요.

QAI가 쓴 대본의 사실은 믿어도 돼요?
A

AI는 날짜·숫자를 그럴듯하게 틀리기도 해요. 숫자마다 출처를 붙여 달라고 하고, 링크를 직접 열어 확인하세요. 이 페이지도 운용 매뉴얼·당시 기사 같은 1차 자료로 확인했어요.

glossary

처음 보는 단어가 있다면

퍼셉트론
입력에 가중치를 곱해 더하고, 기준을 넘으면 1을 내는 가장 단순한 인공 신경망.
가중치(weight)
입력이 결과에 얼마나 세게 영향을 주는지 나타내는 숫자. Mark I에서는 가변저항의 위치.
가변저항(포텐셔미터)
손잡이를 돌려 저항값을 바꾸는 부품. 오디오 볼륨 손잡이와 같은 부품이에요. Mark I은 이걸 모터로 돌려 학습했어요.
연상 유닛(A-unit)
Mark I의 중간층. 빛 센서 신호를 무작위로 받아 계산해요.
역전파(backpropagation)
여러 층의 가중치를 출력 오차로부터 거꾸로 한꺼번에 조정하는 방법.
파라미터
모델이 학습으로 정하는 숫자들. 대부분이 가중치예요.
Veo
구글의 영상 생성 AI. 이 영상은 Veo 3.1 Fast로 8초씩 만들었어요.
Flow
Veo로 영상을 만드는 구글의 작업 화면.
TTS(음성 합성)
글을 넣으면 사람 목소리로 읽어주는 기술.
아티팩트
Claude가 대화 옆에 만들어 바로 실행해 보여주는 페이지·코드 결과물.
컷 목록(샷 리스트)
영상을 장면 단위로 나눠, 컷마다 화면·카메라·얹을 글자를 적은 표.
훅
영상 첫 1~3초에 계속 보게 만드는 첫 문장이나 장면.
