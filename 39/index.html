claude code cheat sheet

모두 Claude Code 공식 문서에서 확인했어요

이렇게 작동해요

  1. 1/effort ultracode큰 작업을 워크플로로 — 여러 에이전트가 나눠 처리 (끄기: /effort ultracode off)
  2. 2/effort max가장 깊은 생각 단계 — 토큰을 많이 쓰고 과하게 생각할 수 있음
  3. 3ultrathink프롬프트 아무 곳에 쓰면 그 턴만 더 깊게 생각 (설정은 그대로)
  4. 4/rewind되감기 메뉴(코드·대화 복원) — 입력창 비우고 Esc 두 번도 같음
  5. 5claude --safe-modeCLAUDE.md·스킬·MCP·훅을 끄고 시작 — 꼬였을 때 원인 찾기

깊게 생각하게 하는 건 ultrathink(한 번)와 /effort max(계속), 일을 나눠 맡기는 건 ultracode, 실수를 되돌리는 건 /rewind, 설정이 꼬였을 땐 --safe-mode예요. 깊게 생각할수록 토큰과 시간이 더 들어서, 작은 일에는 기본값이 더 나아요.

명령어 하나씩

method
01STEP 1ultracode

01 /effort ultracode — 큰 일은 AI 팀으로

  • ultracode를 켜면 Claude가 큰 작업을 워크플로(작업 순서를 담은 스크립트)로 짜고, 여러 에이전트에게 나눠 맡겨요. 영상 속 애니메이션도 이 방식으로 만들어졌어요.
    1. 1켜기: /effort ultracode
    2. 2끄기: /effort ultracode off
    3. 3처음부터 켜고 시작: claude --effort ultracode
    4. 4Opus 5.5·Sonnet 5.5 등 xhigh를 지원하는 모델에서 동작
  • 예시
    /effort ultracode

이 저장소 전체에서 사용하지 않는 함수와 파일을 찾아줘.
1) 파일마다 나눠서 검사하고
2) 찾은 것은 서로 교차 확인한 뒤
3) 지워도 되는 것만 목록으로 정리해줘. 아직 지우지는 마.
  • 주의에이전트가 여럿 돌기 때문에 토큰을 많이 써요. 파일 하나 고치기 같은 작은 일에는 끄는 게 나아요.
02STEP 2max

02 /effort max — 최대로 생각

  • max는 가장 깊게 생각하는 단계예요. 공식 문서도
    효과가 줄어들 수 있고 과하게 생각하기 쉬우니 넓게 쓰기 전에 먼저 시험해 보라
  • 예시
    /effort max

(정말 어려운 문제 하나만) 결제 금액이 가끔 1원씩 틀리는 버그의 원인을 찾아줘.
끝나면 /effort auto 로 되돌릴 것.
  • TIP/effort auto로 저장된 단계를 해제할 수 있어요.
03STEP 3ultrathink

03 ultrathink — 그 질문만 더 깊게

  • 프롬프트 아무 곳에 ultrathink라고 쓰면, 세션 설정은 그대로 두고 그 한 번만 더 깊게 생각해요.
  • 예시
    ultrathink
이 함수가 가끔 빈 배열을 돌려주는 원인을 찾아줘. 가능한 원인을 3개까지 적고, 각각 확인하는 방법도 알려줘.
  • 주의공식 문서 기준으로 인식하는 키워드는 ultrathink 하나예요. "think", "think hard" 같은 말은 따로 인식하지 않아요.
04STEP 4/rewind

04 /rewind — 되감기

  • /rewind를 입력하면(입력창이 비었을 때 Esc 두 번도 같아요) 되감기 메뉴가 열려요. 프롬프트를 보낼 때마다 저장되는 체크포인트로, 코드와 대화를 이전 시점으로 함께 또는 따로 되돌리거나 그 지점부터 요약할 수 있어요.
    1. 1코드와 대화 복원
    2. 2대화만 복원
    3. 3코드만 복원
    4. 4여기부터 요약 / 여기까지 요약
  • 주의Bash 명령(rm, mv 등)으로 바뀐 파일은 되돌리지 못해요. 오래 보관할 기록은 Git으로 관리하세요.
05STEP 5safe-mode

05 claude --safe-mode — 꼬였을 때 깨끗하게

  • 갑자기 Claude Code가 이상하게 굴면, 내가 추가한 설정 중 무엇이 문제인지 찾기 어려워요. claude --safe-mode로 시작하면 CLAUDE.md, 스킬, MCP, 훅을 모두 끈 상태로 열려서, 문제가 설정 탓인지 바로 확인할 수 있어요.
  • 터미널에서
    claude --safe-mode
  • TIP안전 모드에서 문제가 사라지면 → 스킬·MCP·훅을 하나씩 다시 켜며 범인을 찾으면 돼요.
06STEP 6만든 법

영상 속 애니메이션은 이렇게 만들었어요

troubleshooting

자주 막히는 부분을 모았어요

QClaude 앱(채팅)에서도 되나요?
A

아니요. 이 페이지의 명령어는 터미널에서 쓰는 Claude Code 기준이에요.

Qultracode를 켜면 무조건 좋아지나요?
A

큰 작업에 맞는 기능이에요. 작은 수정에는 시간과 토큰만 더 들 수 있어요.

Q명령어가 안 먹어요.
A

Claude Code 버전이 낮으면 일부 기능이 없을 수 있어요. 업데이트 후 다시 해보세요. 공식 문서 기준: --effort ultracode는 v2.1.203 이상.
