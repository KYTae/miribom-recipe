이렇게 작동해요

  1. 1/effort ultracode큰 작업을 워크플로로 — 여러 에이전트가 나눠 처리 (끄기: /effort ultracode off)
  2. 2/effort max가장 깊은 생각 단계 — 토큰을 많이 쓰고 과하게 생각할 수 있음
  3. 3ultrathink프롬프트 아무 곳에 쓰면 그 턴만 더 깊게 생각 (설정은 그대로)
  4. 4/rewind되감기 메뉴(코드·대화 복원) — 입력창 비우고 Esc 두 번도 같음
  5. 5claude --safe-modeCLAUDE.md·스킬·MCP·훅을 끄고 시작 — 꼬였을 때 원인 찾기

깊게 생각하게 하는 건 ultrathink(한 번)와 /effort max(계속), 일을 나눠 맡기는 건 ultracode, 실수를 되돌리는 건 /rewind, 설정이 꼬였을 땐 --safe-mode예요. 깊게 생각할수록 토큰과 시간이 더 들어서, 작은 일에는 기본값이 더 나아요.

준비물

  • Claude Code터미널에서 쓰는 Claude. 이 페이지의 명령어는 Claude 채팅 앱에서는 안 돼요
  • 최신 버전오래된 버전이면 일부 명령이 없어요. 공식 문서 기준 --effort ultracode는 v2.1.203 이상
  • xhigh를 지원하는 모델ultracode는 Opus 5.5·Sonnet 5.5처럼 xhigh를 지원하는 모델에서 동작해요
  • Git되감기는 세션 안에서만 돼요. 오래 남길 기록과 Bash로 바꾼 파일은 Git 커밋으로 지키세요
  • 연습용 프로젝트처음엔 망가져도 괜찮은 복사본 저장소에서 시험해 보세요

01STEP 1ultracode

01 /effort ultracode — 큰 일은 AI 팀으로

  • ultracode를 켜면 Claude가 큰 작업을 워크플로(작업 순서를 담은 스크립트)로 짜고, 여러 에이전트에게 나눠 맡겨요. 영상 속 애니메이션도 이 방식으로 만들어졌어요.
    1. 1켜기: /effort ultracode
    2. 2끄기: /effort ultracode off
    3. 3처음부터 켜고 시작: claude --effort ultracode
    4. 4Opus 5.5·Sonnet 5.5 등 xhigh를 지원하는 모델에서 동작
  • 예시
    /effort ultracode

이 저장소 전체에서 사용하지 않는 함수와 파일을 찾아줘.
1) 파일마다 나눠서 검사하고
2) 찾은 것은 서로 교차 확인한 뒤
3) 지워도 되는 것만 목록으로 정리해줘. 아직 지우지는 마.
  • 주의에이전트가 여럿 돌기 때문에 토큰을 많이 써요. 파일 하나 고치기 같은 작은 일에는 끄는 게 나아요.
02STEP 2max

02 /effort max — 최대로 생각

  • max는 가장 깊게 생각하는 단계예요. 공식 문서도
    효과가 줄어들 수 있고 과하게 생각하기 쉬우니 넓게 쓰기 전에 먼저 시험해 보라
  • 예시
    /effort max

(정말 어려운 문제 하나만) 결제 금액이 가끔 1원씩 틀리는 버그의 원인을 찾아줘.
끝나면 /effort auto 로 되돌릴 것.
  • TIP/effort auto로 저장된 단계를 해제할 수 있어요.
03STEP 3ultrathink

03 ultrathink — 그 질문만 더 깊게

  • 프롬프트 아무 곳에 ultrathink라고 쓰면, 세션 설정은 그대로 두고 그 한 번만 더 깊게 생각해요.
  • 예시
    ultrathink
이 함수가 가끔 빈 배열을 돌려주는 원인을 찾아줘. 가능한 원인을 3개까지 적고, 각각 확인하는 방법도 알려줘.
  • 주의공식 문서 기준으로 인식하는 키워드는 ultrathink 하나예요. "think", "think hard" 같은 말은 따로 인식하지 않아요.
  • 피할 것
    • think hard 같은 말로 대신 쓰기 — 따로 인식하지 않아요
    • 쉬운 질문마다 붙이기 — 시간과 토큰만 늘어요
04STEP 4/rewind

04 /rewind — 되감기

  • /rewind를 입력하면(입력창이 비었을 때 Esc 두 번도 같아요) 되감기 메뉴가 열려요. 프롬프트를 보낼 때마다 저장되는 체크포인트로, 코드와 대화를 이전 시점으로 함께 또는 따로 되돌리거나 그 지점부터 요약할 수 있어요.
    1. 1코드와 대화 복원
    2. 2대화만 복원
    3. 3코드만 복원
    4. 4여기부터 요약 / 여기까지 요약
  • 주의Bash 명령(rm, mv 등)으로 바뀐 파일은 되돌리지 못해요. 오래 보관할 기록은 Git으로 관리하세요.
    1. 1입력창을 비운 상태에서 Esc 두 번, 또는 /rewind 입력
    2. 2되돌아갈 시점(그때 보낸 프롬프트) 고르기
    3. 3코드와 대화 / 대화만 / 코드만 중 복원 방식 고르기
05STEP 5safe-mode

05 claude --safe-mode — 꼬였을 때 깨끗하게

  • 갑자기 Claude Code가 이상하게 굴면, 내가 추가한 설정 중 무엇이 문제인지 찾기 어려워요. claude --safe-mode로 시작하면 CLAUDE.md, 스킬, MCP, 훅을 모두 끈 상태로 열려서, 문제가 설정 탓인지 바로 확인할 수 있어요.
  • 터미널에서
    claude --safe-mode
  • TIP안전 모드에서 문제가 사라지면 → 스킬·MCP·훅을 하나씩 다시 켜며 범인을 찾으면 돼요.
    1. 1터미널에서 claude --safe-mode 로 시작
    2. 2문제가 생기던 작업을 똑같이 다시 해보기
    3. 3문제가 사라지면 설정 탓 — 스킬·MCP·훅을 하나씩 다시 켜며 확인

05/effort max — 정말 어려운 문제 하나만
/effort max

[어려운 문제, 예: 동시에 주문하면 재고가 마이너스가 돼요]
- 관련 파일: [예: order.py, stock.py]

2) 고치는 방법을 2가지 이상 비교한 뒤 가장 안전한 방법 하나를 골라 고쳐줘

max는 토큰을 많이 써요 — 어려운 문제 하나 끝나면 /effort auto

06/rewind 대비 — 되돌릴 수 있게 작업 부탁
이번 작업은 나중에 /rewind로 되돌릴 수도 있어. 그래서:
- 파일 내용 수정은 편집으로만 하고, rm·mv 같은 Bash 명령으로 파일을 지우거나 옮기기 전에는 꼭 나한테 먼저 물어봐
- 시작 전에 git 상태를 확인하고, 커밋 안 된 변경이 있으면 알려줘
작업: [할 일, 예: 설정 화면에 다크 모드 버튼 추가]
단계마다 무엇을 바꿨는지 한 줄씩 적어줘.

Bash로 바꾼 파일은 되감기로 안 돌아와요 — 그래서 미리 약속해 두기

07/rewind 다음 — 다른 방법으로 다시
방금 /rewind로 [되돌린 시점, 예: 로그인 수정 전]까지 되돌렸어.
되돌리기 전에는 [해본 방법, 예: 세션 저장 방식을 통째로 바꾸기]으로 했다가 [생긴 문제, 예: 다른 화면이 다 깨졌어].
이번에는 그 방법은 쓰지 말고, 바꾸는 범위를 최소로 해서 다시 해줘.
먼저 계획을 3줄로 보여주고, 내가 OK하면 시작해줘.

대화까지 되돌리면 Claude는 실패한 시도를 몰라요 — 한 줄로 알려주기

08--safe-mode — 꼬인 설정 범인 찾기
(터미널에서 claude --safe-mode 로 시작한 뒤)

이럴 땐 이렇게

troubleshooting

자주 막히는 부분을 모았어요

QClaude 앱(채팅)에서도 되나요?
A

아니요. 이 페이지의 명령어는 터미널에서 쓰는 Claude Code 기준이에요.

Qultracode를 켜면 무조건 좋아지나요?
A

큰 작업에 맞는 기능이에요. 작은 수정에는 시간과 토큰만 더 들 수 있어요.

Q명령어가 안 먹어요.
A

Claude Code 버전이 낮으면 일부 기능이 없을 수 있어요. 업데이트 후 다시 해보세요. 공식 문서 기준: --effort ultracode는 v2.1.203 이상.

Q어디에 입력해요?
A

/effort, /rewind, ultrathink는 Claude Code 입력창에 써요. claude --safe-mode와 claude --effort ultracode는 터미널에서 Claude Code를 시작할 때 쓰는 명령이에요.

Q「깊게 생각해」라고 한국어로 써도 돼요?
A

공식 문서 기준으로 인식하는 키워드는 ultrathink 하나예요. 프롬프트 아무 곳에 영어로 ultrathink를 넣으세요.

QEsc를 두 번 눌렀는데 되감기 메뉴가 안 떠요
A

입력창에 글자가 남아 있으면 안 돼요. 입력창을 비운 뒤 다시 누르거나, /rewind를 직접 입력하세요.

Q되감았는데 지운 파일이 안 돌아와요
A

Bash 명령(rm, mv 등)으로 바뀐 파일은 되감기로 돌아오지 않아요. Git에 커밋해 뒀다면 Git으로 되돌리세요. 「대화만 복원」을 골랐다면 코드는 그대로예요.

Qultrathink와 /effort max는 뭐가 달라요?
A

ultrathink는 그 한 번만, /effort max는 바꿀 때까지 계속 깊게 생각해요. 어려운 질문 하나라면 ultrathink가 먼저예요.

Q안전 모드에서 스킬·MCP가 안 돼요
A

정상이에요. 안전 모드는 원인을 찾으려고 CLAUDE.md·스킬·MCP·훅을 끈 상태예요. 확인이 끝나면 평소처럼 claude로 다시 시작하세요.

용어 풀이

glossary

처음 보는 단어가 있다면

effort
Claude가 얼마나 깊게 생각할지 정하는 단계(low~max).
워크플로
여러 에이전트에게 일을 나눠 주는 순서를 담은 스크립트.
에이전트
맡은 일을 스스로 처리하는 Claude 작업자.
체크포인트
프롬프트를 보낼 때마다 저장되는 되돌리기 지점.
CLAUDE.md
프로젝트 규칙을 적어 두면 Claude Code가 작업할 때 읽는 파일.
스킬
특정 작업 방법을 담아 둔 지시 묶음. 필요할 때 Claude가 꺼내 써요.
MCP
Claude를 다른 프로그램·서비스와 연결하는 방식.
훅
정해진 순간(예: 파일 수정 뒤)에 자동으로 실행되도록 걸어 둔 명령.
토큰
AI가 글을 처리하는 단위. 깊게 생각할수록, 에이전트가 많을수록 많이 써요.
Git 커밋
지금 파일 상태를 기록해 두는 저장 지점. 세션이 끝나도 남아요.
